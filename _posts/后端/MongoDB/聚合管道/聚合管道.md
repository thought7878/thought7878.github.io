
# 为什么使用聚合管道？
[[为什么使用聚合管道？]]

这个问题问到了根子上。简单来说，**使用聚合管道最根本的原因，是“把计算带到数据身边，而不是把数据搬到应用层来算”。**

在你之前的理解基础上，我把它的核心价值拆解为 **3个维度**，你就明白为什么它如此重要了：

### 1. 性能维度：避免“内存爆炸”和网络拥堵
这是最实际的原因。如果你不用聚合管道，要实现“按地区统计年销售额”，你只能先把**所有**订单记录（可能几百万条）从数据库拉到应用服务器的内存里，再用代码循环累加。

- **用管道**：`$group` 在数据库进程内完成分组求和，只把**最终统计结果**（几十条）传回应用。
- **不用管道**：海量原始数据要在网络间传输，应用服务器内存瞬间占满，GC（垃圾回收）卡顿。管道利用数据库底层的 C++ 引擎和索引，比应用层代码快 **1-2个数量级**。

### 2. 功能维度：一站式解决“复杂关联和嵌套”
你之前已经了解了 `$lookup` 和 `$unwind`。这解决了MongoDB作为文档数据库最大的“痛点”——**关联查询**。

- **为什么非用不可**：如果你的用户表和订单表分离，或者订单里嵌套了商品数组。用简单的 `find` 查询，要么无法关联，要么只能“先查用户 -> 再循环查订单”（N+1 问题，性能灾难）。
- **管道的好处**：`$lookup` 在数据库侧一次性完成“用户+订单列表”的组装，返回给你一个完整的、可直接渲染的 JSON 嵌套结构。这省去了应用层编写大量胶水代码的繁琐工作。

### 3. 架构维度：替代过时的 MapReduce
在早期版本中，MongoDB 提供 MapReduce 来做复杂聚合。但现在官方**强烈建议废弃它**并全面转向聚合管道：

- **MapReduce** 依赖 JavaScript 解释器，执行慢，且内存使用有严格限制（不能超过 100MB）。
- **聚合管道** 是原生 C++ 实现的，编译执行，且支持**磁盘溢出**（允许数据量超过内存限制时写入磁盘），能处理真正的海量数据。

---

### 什么时候“非用不可”？
当你遇到以下场景时，聚合管道就是唯一正确的选择：

1.  **实时报表**：需要按时间戳（年/月/日）分组、求平均、算环比。
2.  **数据清洗**：需要把数组拆开（`$unwind`）再重组（`$group`），转换字段类型。
3.  **分页+总条数**：需要 `$facet` 同时返回“分页数据列表”和“符合条件的总数”，避免发两次请求。
4.  **地理聚合**：计算每个区域内的坐标点数量。

### 唯一不需要用的场景
如果你的需求只是**简单的等值查询**（`find({ status: "active" })`）或**简单的正序排序**，直接用 `find()` + `sort()` 即可，这时候引入聚合管道反而因为解析管道语法增加了微小的开销，属于“杀鸡用牛刀”。

---

**总结一句**：聚合管道不是“MongoDB 的花哨彩蛋”，而是它处理**批量数据（Batch Processing）** 和 **分析型（Analytical）** 需求的**核心发动机**。没有它，MongoDB 就只是个增强版的 KV（键值）缓存，无法胜任大数据分析。


MongoDB 的**聚合管道（Aggregation Pipeline）**是一种用于对集合中的文档进行数据处理和分析的框架。它把文档依次传入多个“阶段（Stage）”，每个阶段对数据进行转换、过滤、分组、排序、统计等操作，最终输出聚合结果。

可以把聚合管道理解为一条流水线：

```text
原始文档
  -> $match 过滤
  -> $group 分组统计
  -> $sort 排序
  -> $project 字段投影
  -> 最终结果
```

---

# 一、基本语法

MongoDB 中使用 `aggregate()` 方法执行聚合管道：

```javascript
db.collection.aggregate([
  { $stage1: ... },
  { $stage2: ... },
  { $stage3: ... }
])
```

例如：

```javascript
db.orders.aggregate([
  {
    $match: { status: "paid" }
  },
  {
    $group: {
      _id: "$userId",
      totalAmount: { $sum: "$amount" }
    }
  },
  {
    $sort: { totalAmount: -1 }
  }
])
```

这个例子的含义是：

1. 过滤出 `status` 为 `"paid"` 的订单；
2. 按 `userId` 分组；
3. 计算每个用户的订单总金额；
4. 按总金额降序排序。

# 二、聚合管道常用阶段

## 1. `$match`：**过滤**文档

类似 `find()` 中的查询条件。

```javascript
{
  $match: {
    status: "paid",
    amount: { $gt: 100 }
  }
}
```

作用：**只保留符合条件的文档**。

---

## 2. `$group`：分组统计

用于按某个字段分组，并进行统计计算。

```javascript
{
  $group: {
    _id: "$category",
    totalSales: { $sum: "$sales" },
    count: { $sum: 1 }
  }
}
```

示例数据：

```javascript
[
  { category: "phone", sales: 100 },
  { category: "phone", sales: 200 },
  { category: "laptop", sales: 300 }
]
```

执行后：

```javascript
[
  { _id: "phone", totalSales: 300, count: 2 },
  { _id: "laptop", totalSales: 300, count: 1 }
]
```

---

## 3. `$project`：字段投影

用于选择、重命名、计算字段。

```javascript
{
  $project: {
    _id: 0,
    productName: "$name",
    total: { $multiply: ["$price", "$quantity"] }
  }
}
```

作用：

- `_id: 0` 表示不返回 `_id`
- `productName` 是重命名后的字段
- `total` 是计算出来的新字段

---

## 4. `$sort`：排序

```javascript
{
  $sort: { totalAmount: -1 }
}
```

- `1` 升序
- `-1` 降序

---

## 5. `$limit`：限制返回数量

```javascript
{
  $limit: 10
}
```

---

## 6. `$skip`：跳过指定数量

```javascript
{
  $skip: 20
}
```

常用于分页：

```javascript
db.orders.aggregate([
  { $skip: 20 },
  { $limit: 10 }
])
```

---

## 7. `$lookup`：连表查询

类似 SQL 中的 `LEFT JOIN`。

```javascript
{
  $lookup: {
    from: "users",
    localField: "userId",
    foreignField: "_id",
    as: "userInfo"
  }
}
```

含义：

- 从 `users` 集合中查找数据
- 当前集合的 `userId` 对应 `users._id`
- 查询结果放到 `userInfo` 字段中

例如订单集合：

```javascript
{
  _id: 1,
  item: "iPhone",
  userId: 1001
}
```

用户集合：

```javascript
{
  _id: 1001,
  name: "张三"
}
```

执行 `$lookup` 后：

```javascript
{
  _id: 1,
  item: "iPhone",
  userId: 1001,
  userInfo: [
    {
      _id: 1001,
      name: "张三"
    }
  ]
}
```

---

## 8. `$unwind`：**展开数组**

如果某个字段是数组，可以使用 `$unwind` **将数组拆成多个文档**。

示例：

```javascript
{
  _id: 1,
  tags: ["java", "mongodb", "redis"]
}
```

执行：

```javascript
{
  $unwind: "$tags"
}
```

结果：

```javascript
[
  { _id: 1, tags: "java" },
  { _id: 1, tags: "mongodb" },
  { _id: 1, tags: "redis" }
]
```

---

## 9. `$addFields`：新增字段

```javascript
{
  $addFields: {
    total: { $multiply: ["$price", "$quantity"] }
  }
}
```

---

## 10. `$set`：设置字段

`$set` 是 `$addFields` 的别名。

```javascript
{
  $set: {
    total: { $multiply: ["$price", "$quantity"] }
  }
}
```

---

## 11. `$unset`：删除字段

```javascript
{
  $unset: ["password", "token"]
}
```

或者：

```javascript
{
  $unset: "password"
}
```

---

## 12. `$count`：统计数量

```javascript
{
  $count: "total"
}
```

例如：

```javascript
db.orders.aggregate([
  {
    $match: { status: "paid" }
  },
  {
    $count: "paidCount"
  }
])
```

结果：

```javascript
[
  { paidCount: 128 }
]
```

---

## 13. `$facet`：多管道聚合

可以在一次聚合中执行多个子管道。

```javascript
db.products.aggregate([
  {
    $facet: {
      priceStats: [
        {
          $group: {
            _id: null,
            avgPrice: { $avg: "$price" },
            maxPrice: { $max: "$price" }
          }
        }
      ],
      categoryCount: [
        {
          $group: {
            _id: "$category",
            count: { $sum: 1 }
          }
        }
      ]
    }
  }
])
```

结果类似：

```javascript
[
  {
    priceStats: [
      { _id: null, avgPrice: 299, maxPrice: 999 }
    ],
    categoryCount: [
      { _id: "phone", count: 20 },
      { _id: "laptop", count: 15 }
    ]
  }
]
```

---

## 4. 最小值 `$min`

```javascript
{ $min: "$price" }
```

---

## 5. 数组操作 `$push`

```javascript
{ $push: "$name" }
```

示例：

```javascript
db.orders.aggregate([
  {
    $group: {
      _id: "$userId",

    }
  }

```

---

## 6. 去重数组 `$addToSet`

```javascript

```

和 `$push` 类似，但会去重。

---

## 7. 取第一个值 `$first`

```javascript
{ $first: "$createdAt" }
```

---

## 8. 取最后一个值 `$last`

```javascript
{ $last: "$createdAt" }
```

通常需要配合 `$sort` 使用。

# 四、常用表达式

## 1. 条件表达式 `$cond`

```javascript
{
  $cond: {
    if: { $gte: ["$score", 60] },
    then: "及格",
    else: "不及格"
  }
}
```

示例：

```javascript
db.students.aggregate([
  {
    $project: {
      name: 1,
      result: {
        $cond: {
          if: { $gte: ["$score", 60] },
          then: "及格",
          else: "不及格"
        }
      }
    }
  }
])
```

---

## 2. 字符串拼接 `$concat`

```javascript
{
  $concat: ["$firstName", " ", "$lastName"]
}
```

---

## 3. 数学计算

```javascript
{ $multiply: ["$price", "$quantity"] }
```

常见数学操作：

```javascript
{ $add: ["$a", "$b"] }
{ $subtract: ["$a", "$b"] }
{ $multiply: ["$a", "$b"] }
{ $divide: ["$a", "$b"] }
{ $mod: ["$a", "$b"] }
```

---

## 4. 日期处理

```javascript
{ $year: "$createdAt" }
{ $month: "$createdAt" }
{ $dayOfMonth: "$createdAt" }
{ $dateToString: { format: "%Y-%m-%d", date: "$createdAt" } }
```

示例：按天统计订单数量：

```javascript
db.orders.aggregate([
  {
    $group: {
      _id: {
        $dateToString: {
          format: "%Y-%m-%d",
          date: "$createdAt"
        }
      },
      count: { $sum: 1 }
    }
  }
])
```

# 五、完整示例

假设有订单集合 `orders`：

```javascript
[
  {
    userId: 1,
    item: "iPhone",
    amount: 6000,
    status: "paid",
    createdAt: ISODate("2026-01-01")
  },
  {
    userId: 1,
    item: "AirPods",
    amount: 1000,
    status: "paid",
    createdAt: ISODate("2026-01-02")
  },
  {
    userId: 2,
    item: "MacBook",
    amount: 12000,
    status: "unpaid",
    createdAt: ISODate("2026-01-03")
  }
]
```

统计每个用户已支付订单的总金额：

```javascript
db.orders.aggregate([
  {
    $match: {
      status: "paid"
    }
  },
  {
    $group: {
      _id: "$userId",
      totalAmount: { $sum: "$amount" },
      orderCount: { $sum: 1 }
    }
  },
  {
    $sort: {
      totalAmount: -1
    }
  },
  {
    $project: {
      _id: 0,
      userId: "$_id",
      totalAmount: 1,
      orderCount: 1
    }
  }
])
```

结果：

```javascript
[
  {
    userId: 1,
    totalAmount: 7000,
    orderCount: 2
  }
]
```

# 六、多表关联示例

订单集合 `orders`：

```javascript
{
  _id: 1,
  userId: 1001,
  amount: 6000
}
```

用户集合 `users`：

```javascript
{
  _id: 1001,
  name: "张三"
}
```

查询订单及用户信息：

```javascript
db.orders.aggregate([
  {
    $lookup: {
      from: "users",
      localField: "userId",
      foreignField: "_id",
      as: "user"
    }
  },
  {
    $unwind: "$user"
  },
  {
    $project: {
      _id: 0,
      amount: 1,
      userName: "$user.name"
    }
  }
])
```

结果：

```javascript
[
  {
    amount: 6000,
    userName: "张三"
  }
]
```

# 八、分页示例

```javascript
db.orders.aggregate([
  {
    $match: {
      status: "paid"
    }
  },
  {
    $sort: {
      createdAt: -1
    }
  },
  {
    $skip: 0
  },
  {
    $limit: 10
  }
])
```

如果同时需要总数，可以用 `$facet`：

```javascript
db.orders.aggregate([
  {
    $match: {
      status: "paid"
    }
  },
  {
    $facet: {
      list: [
        { $sort: { createdAt: -1 } },
        { $skip: 0 },
        { $limit: 10 }
      ],
      total: [
        { $count: "count" }
      ]
    }
  }
])
```

# 九、聚合管道性能优化

## 1. 尽早使用 `$match`

越早过滤数据，后续处理的数据量越小。

推荐：

```javascript
[
  { $match: { status: "paid" } },
  { $group: { _id: "$userId", total: { $sum: "$amount" } } }
]
```

不推荐：

```javascript
[
  { $group: { _id: "$userId", total: { $sum: "$amount" } } },
  { $match: { _id: { $ne: null } } }
]
```

---

## 2. `$match` 配合索引

如果 `$match` 条件字段有索引，性能会更好。

例如：

```javascript
db.orders.createIndex({ status: 1, createdAt: -1 })
```

然后：

```javascript
db.orders.aggregate([
  {
    $match: {
      status: "paid",
      createdAt: { $gte: ISODate("2026-01-01") }
    }
  }
])
```

---

## 3. `$project` 尽早减少字段

如果后续阶段不需要某些字段，可以尽早投影掉。

```javascript
{
  $project: {
    userId: 1,
    amount: 1
  }
}
```

---

## 4. 避免大数据量 `$lookup`

`$lookup` 可能带来较大性能开销，尤其是没有索引时。

建议：

- 关联字段建立索引；
- 尽量先用 `$match` 缩小范围；
- 能用嵌入文档解决时，不一定非要 `$lookup`。

---

## 5. `$unwind` 谨慎使用

如果数组很大，`$unwind` 会导致文档数量成倍增长。

例如：

```javascript
{
  items: ["a", "b", "c"]
}
```

`$unwind` 后会变成 3 个文档。

如果数组非常大，要考虑是否必须展开。

# 十、聚合管道和 MapReduce 的区别

| 对比项 | 聚合管道 | MapReduce |
|---|---|---|
| 使用难度 | 更简单 | 较复杂 |
| 性能 | 通常更好 | 通常较慢 |
| 适用场景 | 常见聚合分析 | 复杂自定义计算 |
| 推荐程度 | 优先推荐 | 特殊场景使用 |

现在大多数场景都优先使用聚合管道。

# 十二、简单总结

MongoDB 聚合管道的核心思想是：

```text
数据文档进入管道
-> 经过多个阶段处理
-> 输出最终聚合结果
```

常用阶段包括：

```javascript
$match     // 过滤
$group     // 分组统计
$project   // 字段投影
$sort      // 排序
$limit     // 限制数量
$skip      // 跳过
$lookup    // 关联查询
$unwind    // 展开数组
$addFields // 新增字段
$facet     // 多管道聚合
```

最常用的组合是：

```javascript
db.collection.aggregate([
  { $match: { ... } },
  { $group: { ... } },
  { $sort: { ... } },
  { $project: { ... } }
])
```

如果你要做报表统计、数据分析、分组汇总、关联查询、TopN 排名等，MongoDB 聚合管道是非常核心的工具。
