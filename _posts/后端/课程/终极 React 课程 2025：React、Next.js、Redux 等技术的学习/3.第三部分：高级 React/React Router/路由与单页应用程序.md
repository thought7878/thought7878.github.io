

这份字幕文件主要介绍了 `React Router` 和 `单页应用（SPA, Single-Page Applications）` 的*核心概念、工作原理、其在 React 开发中的重要性*。

以下是内容的详细总结：

## 1. 什么是路由（Routing）？
*   `核心定义`：路由就是**将不同的 URL 映射到用户界面中的不同视图**（在 React 中，即*映射到不同的 React 组件*）。这种映射关系被称为“路由（route）”。
*   `作用`：**当用户访问特定 URL（如 `/`、`/login`、`/app`）时，会渲染对应的组件**。这让用户可以通过浏览器 URL 和链接**在不同页面间导航**，同时**保持 UI 与浏览器 URL 的同步**。

## 2. React 与 React Router
*   **React 的特性**：与其他一些自带路由功能的前端框架不同，React 本身不包含路由功能，而是依赖第三方库。
*   **React Router**：这是 React 生态中最重要、最常用的第三方路由库。学习 React 开发必须掌握它，因为它是构建单页应用的基础。

## 3. 什么是单页应用（SPA）？
*   **核心定义**：SPA 是完全在客户端（用户的浏览器）中运行的 Web 应用程序。
*   **工作原理**：
    1. 用户点击 Router 提供的特殊链接。
    2. 浏览器的 URL 发生改变，但**不会触发整个页面的重新加载（No hard reload）**。
    3. JavaScript（React 和 React Router）拦截该变化，并更新 DOM，仅渲染与新 URL 对应的新组件。
*   **核心优势**：因为没有完整的页面刷新，应用的响应速度极快，能提供类似于原生桌面或移动应用的流畅用户体验。



## 4. SPA 中的数据获取
*   虽然 SPA 完全在客户端运行且不会重新加载整个页面，但它**仍然可以与服务器通信**。
*   组件可以根据需要通过 Web API 从服务器获取外部数据，只是它不会向服务器请求一个全新的 HTML 页面。

## 5. 总结与进阶
*   虽然之前编写的简单 React 应用也没有页面刷新， technically 算是 SPA，但在**专业且复杂的应用**中，必须依赖完善的 URL 路由能力（即使用 React Router），才能真正发挥出单页应用的优势，实现可维护的复杂导航。
