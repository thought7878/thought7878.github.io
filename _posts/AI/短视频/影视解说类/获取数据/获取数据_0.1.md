
>想获取这些app内的短剧的数据，该如何做？

**先分清你要哪层数据**，路径完全不同：

| 数据层      | 例子              | 难度            |
| -------- | --------------- | ------------- |
| App 级    | 下载量、MAU、评分、版本记录 | 低，公开渠道直接拿     |
| *剧目级元数据* | 剧名、分类、集数、封面、简介  | 中，抓包或网页端      |
| *热度/播放级* | 热度值、榜单排名、播放量    | 中高，多为内部指标，不公开 |
| 内容级      | 视频文件本身          | 别碰，版权风险       |

---

## 路径 A：买现成数据（最省事）

要热度/播放这类核心指标，基本只能买：

- **DataEye**：短剧行业最全，热力值、投放、榜单
- **云合数据 / 艺恩**：正片播放量、长视频口径
- **蝉妈妈（抖音）/ 新榜（抖音）/ 飞瓜（快手）**：红果、抖音短剧频道的数据
- **Sensor Tower / 广大大**：出海 App（ReelShort、DramaBox）的下载和收入

App 级的免费渠道：Apple iTunes API、Google Play scraper（`google-play-scraper` 这个 npm 包）直接拉元数据。

## 路径 B：网页端直接抓（性价比最高）

出海 App 全都有 Web 版，**没有签名加密**，直接解析 JSON：

- ReelShort、DramaBox、ShortMax、NetShort 的网页版都是 SSR 页面，Python `requests` + 解析 `__NEXT_DATA__` 就能拿到整站剧目列表
- 国内 **河马剧场、星芽**也有 H5/Web 端，同套路
- 红果本身没有独立 Web 版，但**番茄小说网页端**有短剧内容，可作补充

## 路径 C：App 抓包逆向（没有 Web 端时）

工具链：

1. **抓包**：iOS 用 Stream，安卓用 HttpCanary，或电脑上 mitmproxy + 模拟器（MuMu/雷电）
2. **找接口**：刷剧目列表，抓分页 JSON 请求，看 URL 和参数规律
3. **写采集脚本**：Python `requests` 翻页 → 存 SQLite/CSV
4. **遇签名加密再升级**：
   - 红果是字节系，有设备签名（Slardar 那套），直接用 Frida + objection hook 掉签名函数
   - 安卓可先 decompile APK（jadx）找接口和密钥，有时是静态的
   - iOS 端部分接口在未越狱环境下用抓包证书也能拿到

## 路径 D：榜单白嫖

各 App 内的「热榜」本身就是数据源。每周定时人工或半自动截图/记录，攒几个月就是时间序列——对趋势分析够用。

---

## 合规红线

- **只采元数据**（标题、分类、播放量这类），别批量下视频
- 控制频率，遵守 robots.txt，别把接口打挂
- 不碰任何用户侧数据（登录后的接口含 token，别爬）
- 采集结果自用可以，公开售卖/再分发有法律风险
