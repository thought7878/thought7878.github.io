## 原理：配音是整条视频的时钟

核心就一句话： **配音，是整条视频的时钟。**

![[_posts/AI/短视频/影视解说类/media/ca7d236b4691672abf2f1ccd081dd50b_MD5.webp]]

配音是时钟，字幕和画面跟着它走

![[_posts/AI/短视频/影视解说类/media/e45d191e066a096e8722ece1d8461ab3_MD5.webp]]

成片里的三条轨道：配音在最下面当时钟

### 第一步：先有配音，再有画面

很多人做视频，习惯先剪画面，再配音，然后一点一点去对。我正好反过来：稿子写好，先把整篇配音生成出来。

这条配音里，第几秒在说什么，就是整条视频的时间表。字幕、画面，全都跟着它走。

![[_posts/AI/短视频/影视解说类/media/335df23f90aacd1557d29d8bd62e4c1f_MD5.webp]]

稿子 → 声音 → 时间 → 画面

### 第二步：算出每个字是第几秒说的

就像拿着歌词本听歌。歌词你早就知道了，因为稿子是你自己写的。你要做的，只是听出每个字从第几秒开始，到第几秒结束。这一步，专业上叫「强制对齐」。

做法有三种：

- **配音模型自己给** ：有的配音平台，生成配音时会一起返回每个字的开始、结束时间；
- **用对齐模型来算** ：比如千问的 Qwen3-ForcedAligner；
- **用剪映** ：如果前两样你都没有，把配音拖进剪映，用它的字幕识别，一样能拿到时间。
![[_posts/AI/短视频/影视解说类/media/ea7d53c6c3134cc1c8f19b13db9aed4d_MD5.webp]]

三种做法：配音模型自己给、对齐模型来算、剪映识别字幕

这三种怎么操作，第三节实操里会一个一个讲。

### 第三步：让 AI 读懂你在讲什么，把画面卡在词上

有了每个字的时间，接下来交给大模型。它会一句一句读你的稿子，判断这句话在讲什么：

- 讲数据，就做成图表；
- 讲步骤，就做成流程；
- 引用别人的原话，就截一张真实的网页，划上荧光笔；
- 提到某个产品，就把它的 logo 放上来。

然后，每一个动画，它都会写成「说到某个词的那一刻，某个东西出现」。

![[_posts/AI/短视频/影视解说类/media/aae878e55cba81b0b2cbd6150720f974_MD5.webp]]

说到哪个词，对应的画面就在那一刻出现

画面不能大概对上，要精确到每一个词。只差半秒，看着马上就别扭了。

### 第四步：为什么导出来不会错位

这些画面，没有一帧是边播边录的，全是按时间一帧一帧算出来的。一秒 60 帧，第 600 帧，就画第 10 秒该有的样子。

全部画完，再把配音放回去。每一帧和声音天然对齐，电脑卡一下也不会错位。

![[_posts/AI/短视频/影视解说类/media/d8cf432e3e0135d8513d3897e65f0596_MD5.webp]]

不录屏，按时间一帧一帧画

原理就这四步： **先有配音，算出每个字的时间，让 AI 把画面卡在词上，最后一帧一帧导出来。**

## 怎么选：四种配音方式

市面上主流的，大概有四种。

![[_posts/AI/短视频/影视解说类/media/d30758faa532da076a951ec207f7aaef_MD5.webp]]

自己配音、机械配音、克隆音色、平台自带的音色

**第一种，自己配音。** 效果肯定最好，优点也很多，但门槛真的太高了。没专门训练过的话，录音、重新录、剪气口、降噪，光是配音花的时间，就可能让你直接放弃。如果你声音本来就不算好听，又不出镜，用 AI 配音完全没问题。所以我不建议一上来就自己配。

**第二种，机械配音** ，就是那种机械感很重的 AI 音色。这种我最不推荐：做着做着，很容易做成营销号。全网都在用的声音，观众是记不住你的。想认认真真做自媒体，别用这种。

**第三种，克隆别人的音色。** 网上很多人在用，但用过的都知道，没那么好用。克隆出来的声音不太自然，除非花大量时间训练，不然观众一听就知道是 AI。大多数人的声音本来也没专门训练过，我觉得没必要折腾。当然，这只针对像我这样做科普、做动画类的视频；做短剧或者别的类型，就另说了。

**第四种，也是我现在用的：用生成式的语音大模型，直接选平台上自带的音色。** 为什么推荐它：

1. 可以自己挑，找到最符合你频道风格的声音；
2. 方便、省时间，不用花多少精力，就能找到一个好听的配音；
3. 效果我不敢说最好，但绝对不差；
4. 它特别方便接进 AI 的工作流。

### 去哪里用

去主流的模型厂商那里，拿到它的 API：

- 国产比较有名的，有豆包、千问、MiniMax；
- 也可以用开源的模型，比如千问开源的 Qwen3-TTS，还有 B 站的 IndexTTS；
- 我个人用的是 ElevenLabs。
![[_posts/AI/短视频/影视解说类/media/517963e4c07a6f20f0d7ba926d7c9a08_MD5.webp]]

国产、海外、开源，主流的配音模型

总之，自己上去挑一个合适的套餐，直接调用它的 API 就行。不知道用什么模型，可以先看看相关的测试排行，哪个能力强、效果好；但最后还是建议你自己实际听一下，觉得不错，就用它。

### 为什么建议用 API

不嫌麻烦的话，直接在它们的网页上生成也可以：把生成好的音频交给字幕模型，生成带时间的字幕文件，一样能用。

但用 API，AI 可以帮你控制得更细：哪里停顿、带什么情绪、长句怎么断开，都能写进去，一次生成就是你想要的样子。想搭一套自己稳定的工作流，我建议直接用 API：模型直接调用，效率能大大提高。

![[_posts/AI/短视频/影视解说类/media/c1e9727cefb5b6d1eed8e65d87bb255f_MD5.webp]]

网页上生成要自己下载、自己跑字幕；用 API，AI 一路调用下来

## 上手实操：DeepSeek 从零做一条 15 秒的科普小动画

为了方便理解，这次演示用的是 DeepSeek，搭配 DeepSeek Harness。换成其他任何 Agent 都可以。

目标是让它从零开始，做一条 15 秒的科普小动画：为什么天空是蓝色的。配音、字幕、画面，全部交给它。

### 准备：一个文件夹，四份文件

先准备一个文件夹，里面放四份文件：

- **稿子** ：这 15 秒要念的话；
- **读法规则** ：告诉它稿子怎么改，配音才不读错；
- **配音设置** ：用哪个平台、key 放在哪；音色先不填，让它自己找；
- **画面要求** ：画面多大、什么配色、字幕怎么放、最后怎么导出。

**技术细节全写在文件里，对话框里我只说大白话。**

![[_posts/AI/短视频/影视解说类/media/4046b4d728c0c1406c391e37c263a420_MD5.webp]]

在 Harness 右边打开工作区文件，一份一份点开看

四份文件的原文如下，可以直接复制，改成你自己的内容。

```js
为什么天空是蓝色的？阳光其实是好几种颜色的光混在一起。穿过大气层时，波长只有 450 纳米左右的蓝光，最容易被空气分子散射，于是铺满了整片天空。
```

```js
# 读法规则

配音之前，先把稿子复制一份，按下面的规则改成「送去配音的版本」。原来的稿子不动，字幕要用它。

1. **型号里的数字写成汉字**，前后留空格：GPT-6 写成「GPT 六」，Gemini 3.8 写成「Gemini 三点八」。不然容易被读成英文，或者名字被读断。
2. **普通数字保持阿拉伯数字**：450 纳米、20 分钟这种，配音模型自己会读对。
3. **容易读错的多音字，换一个意思一样的词**。比如「空白」换成「空的」，「好处」换成「优点」。
4. **长句加逗号**：两个标点之间超过 26 个字，就按意思加一个逗号，让它有地方换气。
5. **段落之间空一行**，读的时候会停得久一点。
```

配音设置.md（这是实操开始时的样子，音色还没定）

```js
# 配音设置

- 配音平台：ElevenLabs
- API key：在同一个文件夹的 \`key.txt\` 里（不要把 key 打印出来，也不要写进代码文件）
- 模型：eleven_v4
- 音色：还没定，先按我想要的风格去平台的音色库里找，出几段试听让我挑
- 整篇稿子一次生成，不要分段
- 生成的东西都放进 \`产物/\`
```

```js
# 画面要求

把分镜做成动画视频时，照这份来。

## 尺寸和导出

- 画面 1920×1080，每秒 60 帧。
- 动画写成一个网页 \`产物/动画.html\`。网页里提供一个函数 \`renderAt(秒)\`：传入任意时间，就画出这一刻的画面。不要让页面自己往前播放。
- 导出视频：用无头浏览器打开网页，从第 0 秒开始，每隔 1/60 秒调用一次 \`renderAt\` 截一张图，一直截到配音结束；再用 ffmpeg 把图片合成视频，合进 \`产物/配音.mp3\`，导出 \`产物/成片.mp4\`。
- 另外做一个预览：直接用浏览器打开网页，就能跟着配音自动播放，方便先看效果。

## 时间：画面要跟着声音走

- 每个动作开始的时间，都从 \`产物/时间.json\` 里按词查出来：说到哪个词，那个动作就在那一刻开始。**不要手填秒数。**

## 好看

- 配色：深夜蓝到天空蓝的渐变底；光用暖金色和白色；文字白色。
- 字体：用 \`字体/\` 文件夹里的 MiSans。
- 每个画面只有一个主角，同屏不超过三样东西，留足空白，不要挤。
- 东西出现和消失都要平滑缓动（淡入、缓慢放大、滑入），不要突然蹦出来，也不要大幅度弹跳。
- 画面之间要连贯：上一个画面的东西变成下一个画面的开头，不要硬切。

## 字幕

- 底部居中，白字加柔和的阴影，字号要大、清楚。
- 字用原稿 \`稿子.txt\` 的原文（不用识别出来的字），去掉标点。
- 一条字幕是一个短句：在逗号、句号处换条，一条不超过 14 个字。
- 每条字幕的出现和消失，都卡在 \`产物/时间.json\` 里那句话真实开始和结束的时间。
```

### 第四步：拿到每个字的时间

这时候文件夹里除了配音，还多了一份时间表：每个字从第几秒开始、到第几秒结束，都写在里面。这是配音平台在生成配音时，一起返回的。有了它，每个字在第几秒，就都知道了。

![[_posts/AI/短视频/影视解说类/media/9e4d15f0c2655e98e8f78acd1a2fe3b5_MD5.webp]]

时间.json 里的逐字时间

但不是每个平台都会给。如果你用的平台不返回时间，或者你是自己录的音、在网页上配的，有两个办法。

**第一个，剪映。** 把配音拖进去，用它的识别字幕，就能拿到每一句的时间。不过要注意，想把字幕导出成文件，要开会员。

![[_posts/AI/短视频/影视解说类/media/3a7e0853c6e5bcff1801fc5deb322576_MD5.webp]]

剪映里右键配音，「识别字幕」

**第二个，也是我推荐的：Qwen3-ASR。** 这是阿里千问今年 1 月开源的语音识别模型，只有 0.6B 参数，一张 4G 显存的显卡就能用。在 GitHub 上搜 Qwen3-ASR 就能找到（ `QwenLM/Qwen3-ASR` ），把地址丢给 AI，它会自己装好。

![[_posts/AI/短视频/影视解说类/media/991f832f2724cc035598743bb92777d7_MD5.webp]]

Qwen3-ASR 的 GitHub 页面

为什么推荐它：第一，模型可以直接调用它，不用你手动去点；第二，方便，准确率也高。后面还能把它做成 MCP，搭进你自己的工作流，我现在就是这么用的。

美术分镜开头是这样写的（全文比较长，这里只放开头和第一个镜头，照这个格式写你自己的）：

# 美术分镜（推翻重做，照这份一项一项实现）

现在的版本从头到尾只有一个太阳加放射光线，像屏保，画面没在讲东西。**不要在它上面改**，按这份从头重写 \`产物/动画.html\`。导出、预览的方法照旧。

画布 1920×1080，左上角是 (0,0)。下面写的坐标、尺寸都是像素，照着写，不要自己发挥。

## 一、禁止

- 放射光线、镜头光晕、星星、噪点、颗粒、暗角、细圆弧：一律不要。
- 细于 6 像素的线不要；除了太阳，任何东西都不加发光、不加模糊。
- 下面色表以外的颜色不要；不要把颜色调灰、调暗。

## 二、色表（节选）

| 用途 | 颜色 |
|---|---|
| 夜空（上 → 下） | \`#0B1B3F\` → \`#1B3A6B\` |
| 太阳 | \`#FFC93C\` |
| 彩虹，从上到下 | \`#FF4D5E\` \`#FF9F40\` \`#FFD93D\` \`#4CD97B\` \`#3DA5FF\` \`#9B6BFF\` |

风格：扁平插画科普片（像 Kurzgesagt）。实心色块、圆角、圆头线。

## 五、分镜

### 镜头 1　「为什么天空是蓝色的」（第 0 秒 → \`T('阳光')\`）

- 夜空背景，地球、大气层、太阳都在。
- 标题「为什么天空是蓝色的？」：字号 110，最粗，白色，中心在 (960, 430)。
- 每个字在配音读到它的那一刻出现：0.3 秒内从下方 20 像素处升上来、淡入。问号跟着最后一个字出现。
- 到 \`T('阳光')\` 时，标题在 0.5 秒内上移 40 像素、淡出。

## 总结

- **原理** 就四步：先有配音，算出每个字的时间，让 AI 把画面卡在词上，最后一帧一帧导出来。
- **选择** 上，我推荐直接用平台自带的音色，用 API 来调用。
- **实操** 上，记住三件事：  
	把 key 和几份说明文件准备好；  
	时间优先用平台返回的，没有就用剪映，或者千问的字幕模型；  
	想要画面好看，就把审美写成它能照做的规格。
