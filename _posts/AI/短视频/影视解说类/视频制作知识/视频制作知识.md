
# 需求

我想做一个短视频，包含的内容是10个左右的高分短剧的介绍，需求如下：
- 如何生成文字稿？文字稿应包含短剧的哪些内容？
- 如何根据文字稿生成配音？
- 如何根据文字稿制作视频素材（如动画）？
- 如何将配音、视频素材合成为最终的短视频？


# 技能、工具

帮我创建一个介绍高分短剧的“视频导演 Skill”的提示词。

```
帮我创建一个介绍高分短剧的“视频导演 Skill”的。

用户输入口播稿后，它需要：

1. 理解开场介绍的、每个短剧的、结尾的原稿，拆成语义分镜。
2. 设计开场介绍的、每个短剧的、结尾的动画分镜。
3. 使用 HyperFrames 或 Remotion，生成分镜的关键帧，用于预览。
4. 确保在没有音频（TTS配音）、字词时间戳的情况下，保证设计的动画能根据音频节奏，安排动画卡点。
5. 汇总音频、字词时间戳、动画，生成完整视频。

导演 Skill 负责理解、规划、调度和验收。
```


```
帮我创建一个“视频导演 Skill”。

用户输入口播稿和素材文件夹后，它需要：

1. 理解口播内容，拆成语义分镜。
2. 判断每段使用真人口播、录屏、IP 动画还是 AI 解说动画。
3. 为每个分镜匹配合适的视觉模板和素材。
4. 调度 HyperFrames、Remotion、IP 动画 Skill、粗剪 Skill 和字幕 Skill 分别执行。
5. 根据音频和字幕节奏安排动画卡点，避免素材遮挡、画面压盖和模板重复。
6. 素材不足时，输出补录清单和具体拍摄要求。
7. 汇总各个 Skill 的结果，生成完整视频和可编辑的剪映草稿。
8. 执行前检查依赖；如果用户没有安装 HyperFrames、Remotion 或相关 Skill，先提醒安装。

导演 Skill 负责理解、规划、调度和验收，不重复实现各专项 Skill 已有的能力。
```
