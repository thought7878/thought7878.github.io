
# 动效升级参考调研 —— 深色极简字卡（F 纯黑居中）方向

> 调研范围：Hyperframes 官网/官方仓库 + GitHub 开源动效项目  
> 用途：把现有「逐元素淡入上浮 + 卡尾淡出」升级为更有冲击力、过渡更丝滑的方案  
> 日期：2026-11-23

## 一、Hyperframes 官方体系（heygen-com/hyperframes）

### 1. Motion Doctrine（动效法则，官方总纲）★重点

- 链接：<https://github.com/heygen-com/hyperframes/blob/main/.agents/skills/motion-doctrine/SKILL.md>
- 特点：不是特效合集，而是「让多场景视频看起来像一个连续镜头」的法则集
- 核心内容与适用场景：

| 法则       | 内容                                              | 对本项目                             |
| -------- | ----------------------------------------------- | -------------------------------- |
| **矢量法则** | 出场决定入场：同轴、同向、速度匹配、双侧都在运动中切                      | 12 张卡之间现在是淡出+淡入（无方向），升级为同轴带速度的切换 |
| **主流方向** | 全片选一个主导方向（默认向左）作为"下一拍"；向上=升华、Z 轴推近=深入、Z 拉远=重大登场 | 90→95 分的排行推进天然适合一个统一方向           |
| **载体**   | 眼睛跟随具体物体：让一个元素（序号、剧名、色块）带着位置和速度跨过切点             | 「第 X 部」序号或评分数字可以做跨卡载体            |
| **因果运动** | 每个动作被上一个动作明显触发，反应与质量成正比                         | 评分滚动触发下一卡入场                      |
| **静默蓄势** | 高潮前保持静止，避免无意义的 idle 呼吸动画                        | 静态字卡天然符合，别加循环动画                  |

- 配套：`references/seam-gate.md`（接缝校验器，数值化验证入场/出场速度匹配、方向一致、零重叠）

### 2. GSAP 动画指南（官网）

- 链接：<https://hyperframes.heygen.com/guides/gsap-animation> 、<https://hyperframes.app/docs/3-guides/3-gsap-animation>
- 特点：确定性渲染契约——`{paused: true}` 时间线 + `window.__timelines` 注册，框架逐帧 seek
- 关键实践：
  - 优先 `fromTo()`（随机 seek 可靠，正是我们逐帧渲染的场景）
  - 只动 opacity/transform，不动 width/height/top/left（避免布局重排掉帧）
  - `tl.set({}, {}, DURATION)` 把时间线撑到素材长度

### 3. 官方转场目录（docs/catalog/blocks/）

- 链接：<https://github.com/heygen-com/hyperframes/tree/main/docs/catalog/blocks>
- 每类一个可运行 showcase（mdx + json），可直接抄参数：

| 目录                         | 效果                                                                        | 贴合度            |
| -------------------------- | ------------------------------------------------------------------------- | -------------- |
| `transitions-blur.mdx`     | 出卡 `blur(15px)+scale(1.05)` 收走，进卡 `blur(0)` 落定                            | ★★★ 最贴深色极简     |
| `transitions-scale.mdx`    | Z 轴推拉：`scale 0.3→1` + `blur 8→0`                                          | ★★ 适合"第一部压轴登场" |
| `transitions-light.mdx`    | 光晕扫过 + flash-overlay 亮度脉冲                                                 | ★ 开场/结尾可用      |
| `transitions-dissolve.mdx` | 双侧 `blur(10px)` 交叉溶解（0.5s power2.inOut）                                   | ★★ 兜底方案        |
| 其余                         | push / cover / radial / grid / distortion / 3d / destruction / mechanical | 风格不符，略         |

- 组件级：`components/zoom-through-transition.mdx`（穿过去式变焦）、`components/micro-transitions.mdx`、`packages/shader-transitions.mdx`（着色器转场）

### 4. 官方动画护栏（SKILL.md，两条仓库均有）

- 链接：<https://github.com/app-builders-club/design-builder/blob/main/skills/motion/references/video/hyperframes.md>
- **每场景必须全元素入场（gsap.from），无元素凭空出现；除最后一幕外禁止出场动画——转场本身就是出场**
- 每场景至少 3 种不同 ease，场景内不重复同一入场模式
- 首个动画偏移 0.1–0.3s（不留 t=0 空拍，也不顶格开始）
- 深底避免全屏线性渐变（H.264 banding），用径向或纯色+局部光
- 大字 60px+、`font-variant-numeric: tabular-nums`（数字列用等宽数字——评分滚动必备）

## 二、GitHub 开源项目参考

### 1. React Bits（DavidHDev/react-bits，~48k★）★重点

- 链接：<https://github.com/DavidHDev/react-bits> ｜ 文档 <https://reactbits.dev>
- 特点：215+ 动画组件，四套代码变体，纯前端可抄实现
- 适用清单（深色大字卡片直接可用）：
  - **Blur Text**：字符逐个从模糊到清晰——剧名入场
  - **Split Text**：逐字/逐词分割 + stagger——大标题动画的标准姿势
  - **Scrambled / Decrypted Text**：乱码解码——「AI 剧」题材玩味
  - **Count Up**：数字滚动——评分徽章
  - **Gradient Text / Shiny Text**：流光扫过文字——结尾品牌行
  - **Fade Content / Scroll Reveal**：块级入场参考
- 注意：license 为 MIT + Commons Clause，商用 Redistribution 需过一眼

### 2. motion-anything（nexu-io/motion-anything）★重点

- 链接：<https://github.com/nexu-io/motion-anything>
- 特点：403 个动效配方，全部**零依赖、可跑在任何页面**（纯 DOM/CSS/canvas），每个配方声明 `avoid_when` 和"克制预算"—— taste 是显式规则
- 适用清单：
  - `decrypted-text`：随机字符从左到右解出真文
  - `count-up`：带缓动的数字上卷（评分）
  - `true-focus`：焦点框逐词跳、其余模糊——引导视线
  - `shiny-text`：一道光扫过渐变字
  - `bounce-cards`：卡片堆叠弹出入场——「10 部剧总览」页
  - `silk` / `strands`：GPU 流体背景（若结尾想要一点氛围）

### 3. 缓动与节奏规范（三条高质量参考）

- **Annnimate · expo.out 讲解**：<https://annnimate.com/learn/easing/expo-out>
  - expo.out 前 10% 时间走完 50% 距离——"响应感"来源；UI 0.4–0.8s，超过 1.2s 显拖沓；hero 入场用 power4.out 更电影感
- **AntiSlopUI · design-principles**：<https://github.com/Adefebrian/AntislopUI/blob/main/plugins/antislopui/skills/antislopui/references/design-principles.md>
  - 签名 ease 全片只选 1–2 种（如 [0.16,1,0.3,1] + expo.out），混十种=乱、复用两种=设计
  - 时长规范：微交互 0.2–0.4s / 块入场 0.5–0.9s / 大标题 0.9–1.8s（带 stagger）/ **stagger：字符 0.02–0.05s、行 0.08–0.12s**
  - 反面清单："所有东西同款 ease 淡入 20px"就是 slop
- **Animation Patterns Reference**：<https://github.com/valeriibeck-star/claude-skills/raw/main/skills/top-design/references/animation-patterns.md>
  - 完整 cubic-bezier 对照表（[0.76,0,0.24,1] 转场 in-out、[0.34,1.56,0.64,1] back.out 弹性）
  - 逐字上滑模板：外层 `overflow:hidden`，字符 `translateY(100%)` → 0，`expo.out` + `stagger: 0.02`
  - GPU 安全属性白名单（transform/opacity only）

### 4. 略读备选

- **Flex**（<https://github.com/adithyapaib/flex）：新粗野主义> kinetic typography 引擎，40+ 场景预设，风格偏撞色，可借「场景序列」思路
- **Splitting.js**（1.5kb）：只做字符分割+CSS 变量注入，性能洁癖方案
- **kinetic_text**（Flutter，pub.dev）：把 morph 效果（split-flap / odometer / sheen）的描述写得最细，找效果名词时可当词典

## 三、可借鉴的关键思路 → 现有工程升级清单

现状：每卡元素 `opacity + translateY(26px)` 单一 cubic easeOut，卡尾 0.38s 整体淡出，卡间无方向感。

### 升级点（按冲击力/成本排序）

1. **卡间转场从"淡出淡入"改为矢量连续**（抄 Motion Doctrine 矢量法则 + blur 转场）
   - 现状出口：整体 opacity→0（无方向，眼睛动量归零）
   - 升级：全卡 `y: -60 + blur(12px) + scale 1.03` 加速离场（`power2.in`），下一卡从 `y: 60 + blur(12px)` 带初速进场（`power3.out`）——同轴同向、双侧运动中切
   - 全片统一方向（如向上=排行攀升，正好契合 90→95 的叙事）
2. **剧名大字逐字上滑**（抄 React Bits SplitText 模板）
   - 外层 `overflow:hidden`，每字 `translateY(105%) → 0`，`expo.out`，stagger 0.03s
   - 长剧名（12 字）也有电影片头感；锚点时间不变（仍从「《」后第一字起）
3. **评分数字三重奏**（Count Up + blur-in + tabular-nums）
   - 数字滚动已有；加 `filter: blur(6px) → 0` 与 `scale 1.15 → 1`（`power3.out`），加 `font-variant-numeric: tabular-nums` 防抖动
   - 95 分（第一部）可用 `back.out(1.7)` 小幅过冲，强调"压轴"
4. **块入场改瀑布式 + 多 ease 混排**（waterfall entry）
   - 同区块内多个 `<p>` 用 stagger 0.08s 依次上滑，而不是各自独立淡入
   - 标签 `power3.out`、正文 `expo.out`、季名 `power4.out`——每卡 ≥3 种 ease（官方护栏）
5. **开场卡做"静默蓄势"结构**
   - kicker 先入（0.2s），大字逐字上滑 0.9–1.2s 走完（正好铺满口播念完标题的时间），副标题在 3.2s（念到时）以 blur-in 出现——和字级锚点天然配合
6. **结尾卡光效收束**（transitions-light 思路，克制版）
   - 《数剧》品牌行加一道 0.6s 流光扫过（shiny-text 样式），黑底上单点高光不越界

### 工程约束（不破坏现有架构）

- 引擎仍是确定性 `render(t)`：所有新效果用纯函数表达（进度→属性），不用 rAF/随机
- 逐帧渲染下 `filter: blur()` 每帧重算，1080×1920 全卡 blur 有成本——**只对文字层 blur，背景纯黑不动**，或把 blur 换成预烘焙的透明度阶梯
- banding 警告：如加氛围光，用 radial-gradient 局部光而非全屏线性渐变
- 锚点体系保留：所有入场仍锚字级时间戳，「对齐音频」不回退
