>请制定一套完整的文字转语音读法规则，用于指导语音合成系统正确朗读文本。规则应涵盖常见易错场景，包括多音字在不同语境下的正确读音判定、数字与单位的口语化读法、中英文及符号混读处理、专有名词与缩写的读法、标点与停顿的控制。每条规则需说明适用场景、朗读方式及示例，确保规则可执行、可复用，从而减少误读和多音字错误，保证语音输出的准确性。

哥哥，下面这套可直接作为 **TTS 文本规范化与朗读规则 v1.0**。核心原则是：**原字幕与朗读文本分离、优先按词语和语境判断、无法确认时进入人工词典，不让系统瞎猜。**

## 一、总体执行规则

1. **双文本机制**：保留 `source_text` 用于显示，另生成 `speak_text` 用于合成；所有读法替换只修改 `speak_text`。
2. **规则优先级**：人工 SSML 标记 ＞ 语境规则 ＞ 专有名词词典 ＞ 数字与单位规则 ＞ 通用规则 ＞ 合成引擎默认读法。
3. **处理顺序**：保护代码与链接 → 分句分词 → 专有名词最长匹配 → 多音字判定 → 数字和单位 → 英文与符号 → 标点停顿 → 输出 SSML。
4. **局部替换**：词典匹配必须限定词语或上下文，禁止直接全局替换单个多音字。
5. **可追踪**：每次转换记录规则编号、原文、转换结果和词典来源，方便定位误读。

## 二、多音字判定

| 适用场景 | 朗读方式 | 示例 |
|---|---|---|
| 多音字属于固定词语 | 按完整词语设置读音，采用最长词语匹配 | “重庆”读 **chóng qìng**；“重要”读 **zhòng yào** |
| 同字因词义不同而变音 | 根据词义、词性和搭配判定 | “银行”读 **yín háng**；“行走”读 **xíng zǒu** |
| 表示动作或状态 | 结合动词、形容词用法判断 | “长大”读 **zhǎng dà**；“很长的路”读 **cháng** |
| 表示重复或重量 | 根据语义判断 | “重复”读 **chóng fù**；“重量”读 **zhòng liàng** |
| 助词、轻声和语法词 | 按句法功能判断，不逐字套词典 | “他的书”中“的”读 **de**；“目的”中读 **dì** |
| 人名、姓氏、地名 | 使用专名词典，不采用普通词义推断 | “单先生”读 **shàn xiān sheng**；“六安”读 **lù ān**；“台州”读 **tāi zhōu** |
| 局部语境不足 | 扩大至前后一个分句；仍无法确定则标记复核 | “他背着包走了”可结合语境判为 **bēi**，不得只凭单字决定 |
| 未收录的生僻专名 | 保留原文并输出低置信度告警 | 不自动把姓氏“解”统一读成 **jiě**，应确认是否为 **xiè** |

## 三、数字、日期与单位

| 适用场景 | 朗读方式 | 示例 |
|---|---|---|
| 普通整数、千分位数字 | 按数值读，忽略千分位分隔符 | `12,300` → **一万二千三百** |
| 电话、验证码、编号、身份证 | 逐位朗读；电话号码中的 `1` 可读“幺”，同一文本保持一致 | `10086` → **幺零零八六**；`验证码 5082` → **五零八二** |
| 年份 | 默认逐位读 | `2026年` → **二零二六年** |
| 日期 | 年月日依次转换，“日”可按风格改为“号” | `2026-11-03` → **二零二六年十一月三日** |
| 时间 | 默认二十四小时制；分钟不足十分时读出“零” | `15:05` → **十五点零五分** |
| 小数、负数 | 小数点读“点”，小数部分逐位；负号读“负” | `3.14` → **三点一四**；`-5.2` → **负五点二** |
| 分数、比例 | 分数从分母到分子；比例读“比” | `3/4` → **四分之三**；`3:1` → **三比一** |
| 数值范围 | `~`、`～`、范围连字符读“到” | `10～20` → **十到二十** |
| 百分数、千分数 | 先读“百分之”或“千分之” | `0.5%` → **百分之零点五**；`3‰` → **千分之三** |
| 金额 | 按币种和小数转换，人民币口语使用元、角、分 | `¥1299.50` → **一千二百九十九元五角** |
| 长度、重量、面积 | 数值先转换，单位使用统一中文读法 | `10 km` → **十千米**；`5 kg` → **五千克**；`30㎡` → **三十平方米** |
| 温度 | 正温度读“摄氏度”，负温度优先读“零下” | `20°C` → **二十摄氏度**；`-5°C` → **零下五摄氏度** |
| 时长 | 保留小数，或按自然口语换算，但全文统一 | `1.5h` → **一点五小时**，也可统一为 **一小时三十分钟** |
| 版本号、IP 地址 | 分隔点读“点”，各部分逐位或按段读 | `v2.3.1` → **V 二点三点一**；`192.168.1.1` → **一九二点一六八点一点一** |
| 序号 | `第` 后数字按序数读，列表符号本身不读 | `第3步` → **第三步** |

## 四、中英文及符号混读

| 适用场景 | 朗读方式 | 示例 |
|---|---|---|
| 中文句中夹普通英文单词 | 英文按英语发音，前后保留自然短停顿 | “使用 React 构建页面”中 React 按英语单词读 |
| 常见首字母缩写 | 默认逐字母读 | `API` → **A-P-I**；`HTTP` → **H-T-T-P**；`AI` → **A-I** |
| 已形成固定读法的缩写 | 加入例外词典，不机械逐字母读 | `App` 通常读 **/æp/**，不读 A-P-P |
| 单个变量或英文字母 | 按字母名称读 | `A/B 测试` → **A 斜杠 B 测试**，若表示两种方案则读 **A 和 B 测试** |
| 文件名、扩展名 | 主名按词典读，点读“点”，扩展名逐字母 | `App.tsx` → **App 点 T-S-X** |
| 代码标识符 | 教程需要朗读时按驼峰拆词；否则跳过代码块 | `useState` → **use State**；`user_id` → **user 下划线 id** |
| 邮箱 | `@` 读 **at**，域名点读“点” | `a@b.com` → **A at B 点 C-O-M** |
| 网址 | 非必要不逐字朗读，可概括为“链接略”；必须读时按字符规则转换 | `https://` → **H-T-T-P-S 冒号 斜杠 斜杠** |
| 数学运算符 | 根据表达式语义读，不读字符名称 | `a+b=c` → **A 加 B 等于 C**；`6/2` → **六除以二** |
| 连接符与范围符 | 单词内部连字符通常不读，数值范围读“到” | `real-time` 不读连字符；`10-20分钟` → **十到二十分钟** |
| Markdown、HTML 等格式符 | `#`、`*`、反引号、标签等只控制结构，不朗读 | `**重点**` → **重点** |
| 表情、装饰符号、不可读字符 | 默认删除；有明确语义的符号按词典转换 | `⭐⭐⭐` 不读；`A & B` → **A 和 B** |

## 五、专有名词与缩写词典

1. **适用场景**：人名、地名、品牌、产品、技术框架及固定缩写。
2. **词典字段**：至少包含 `原文、读法、类型、语境、优先级、备注`；可补充拼音、IPA 或引擎专用音素。
3. **匹配方式**：优先匹配最长词条，并允许限定上下文，避免误伤普通词。
4. **示例**：`Next.js → Next J-S`、`Node.js → Node J-S`、`单先生 → shàn xiān sheng`。
5. **同形异读**：必须建立不同语境词条；无法靠语境稳定区分时，要求在原文中人工标注。
6. **实现建议**：引擎支持音素时保留原字并标注读音；不支持时，可在 `speak_text` 中使用同音字代替，但不得改动显示字幕。

## 六、标点、停顿与语气

以下时长可作为基准，再根据语速和引擎微调：

| 标点或结构 | 停顿与朗读规则 |
|---|---|
| `，`、`、` | 短停约 **150–250ms**；顿号通常比逗号略短 |
| `。`、`！`、`？` | 句末停约 **300–500ms**，保留陈述、感叹或疑问语气 |
| `；`、`：` | 中停约 **250–350ms**；冒号后避免不必要的长停顿 |
| 段落、场景切换 | 长停约 **500–800ms** |
| 引号、书名号 | 不读标点名称，只读内容，可用轻微停顿体现边界 |
| 括号 | 补充说明前后短停；内容过长时改为独立句 |
| 省略号 | 停约 **400–800ms**，不读“省略号” |
| 破折号 | 表示转折或补充时中停；不读“破折号” |
| 连续标点、装饰标点 | 合并为一个停顿，不叠加出异常长静音 |
| 无标点长句 | 按意群补停顿，但不得拆开固定名称、数字与单位 |

## 七、完整转换示例

原文：

> 2026年11月3日，单先生用 Next.js 开发了3个页面，耗时1.5h，完成度为80%。

朗读文本：

> 二零二六年十一月三日，**shàn**先生用 **Next J-S** 开发了三个页面，耗时一点五小时，完成度为百分之八十。

其中“单”的读音应通过音素或语音层同音替换实现，屏幕字幕仍显示“单先生”。

## 八、验收标准

- 建立覆盖多音字、姓名地名、数字日期、金额单位、英文缩写、符号和停顿的固定测试集。
- 已确认的数字、单位、日期和专名读法必须 **100% 符合词典**；新增规则不得造成旧用例回退。
- 每批次检查“原文—朗读文本—命中规则—音频结果”，无法确认的项目单独列出人工复核。
- 最终以实际音频验收，不能只看转换文本；重点检查多音字、逐位数字、英文切换和不自然停顿。
