先说结论：**这个 seed-audio（文生音频/参考生音频）能力本身没有内置一份"命名音色清单"（没有可选的音色 ID / 下拉音色库）**。它的声音不是从固定列表里挑，而是用下面两种方式确定。

## 方式一：纯文本描述定音色（T2A，工具 `text_to_audio_plus`）

直接在描述里写清人声特征，模型据此生成。可组合的维度：

| 维度      | 常用描述示例                      |
| ------- | --------------------------- |
| 性别 / 年龄 | 男性、女性；少年、青年、中年、老年、沉稳中年男性    |
| 音色气质    | 浑厚、清亮、沙哑、温柔、成熟、沉稳、活泼、亲切、播音腔 |
| 语速节奏    | 语速缓慢、自然流畅、语速快、一字一顿          |
| 情绪状态    | 平静、开心、严肃、轻声、低语、热情           |
| 角色形态    | 旁白、对话、新闻播报、独白、客服播报          |

skill 文档里出现过的人声样例仅为描述示例，并非固定枚举，例如：青年男性、青年女性、中年男性、沉稳的中年男性旁白。实际生成时你可以自由组合，例如"温柔的青年女性、平稳语速、普通话播报"。

## 方式二：参考音频克隆音色（A2A，工具 `audio_to_audio_plus`）

上传 **1～3 条**参考音频，在描述里用 `@音频1 / @音频2 / @音频3` 指定哪个角色用哪条音色，即可直接借用/参考该音频的声音特质；最多 3 个参考音色，且可混用（一部分角色用参考音色、一部分用文字描述）。这是"固定某个特定人声"最可靠的方式。

## 补充说明

- 除了人声，它也能生成环境声、音效、背景音乐等非语音声音，但"音色"概念主要适用于人声。
- 单段音频里可以出现多个不同音色（多角色对话）。
- 上一轮那段中文朗读没有指定音色，由模型按描述默认生成；如果你想让它**固定成某个声音**，最稳妥是提供一段参考音频（方式二）；如果只想要某种风格，直接用文字描述即可（方式一）。

你可以直接告诉我目标（例如"用沉稳中年男声慢速播报那段 TTS 对比文案"，或"沿用某条参考音频的音色再生成一句"），我据此生成。
