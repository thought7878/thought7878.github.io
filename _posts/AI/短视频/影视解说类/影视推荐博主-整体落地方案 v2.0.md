# 影视推荐博主（解决"剧荒"）整体落地方案

> 制定时间：2026-10-29　｜　覆盖：电影 / 电视剧 / AI剧（含漫剧、短剧）  
> 一句话结论：**你不是"推荐更多剧"，你是"帮人少花冤枉的两小时"。交付决策，不交付片单。**

---

## 0. 先定死一件事：你的产品是什么

观众说"剧荒"，实际是三种不同的病，药不一样：

| 症状   | 观众真实的话                | 他缺的不是 | 你要给的                |
| ---- | --------------------- | ----- | ------------------- |
| 选择过载 | "打开 APP 翻了半小时，一个都没点开" | 更多片单  | 排除法：今晚就这三部，其余别看     |
| 风险厌恶 | "怕又是个开头好看后面烂尾的"       | 好评    | 止损点：看到第几集不行就撤       |
| 口味错配 | "评分挺高，但我看着没劲"         | 高分剧   | 口味坐标：你喜欢 XX，这部八成不对味 |

**核心洞察**：对观众来说，选剧的成本是 10 分钟，弃剧的成本是 40–60 分钟。所以真正的价值不在"帮你选"，而在**降低试用成本**——让他 3 分钟内判断这部剧该不该花时间。

这决定了你所有内容的形态：**短决策 + 明确劝退 + 可验证的判断依据**。不是解说，不是安利，是"体检报告"。

---

## 1. 账号定位与目标人群

### 1.1 定位公式

> 为 **【晚上只有 1–2 小时、怕浪费时间、不爱被剧透】的都市上班族**，  
> 在 **【打开 APP 不知道看什么 / 看两集想弃又怕错过】** 的场景下，  
> 提供 **【3 分钟能做完的观影决策 + 明确的弃剧止损线】**，  
> 依据是 **【公开评分卡 + 真实完播记录 + 平台数据交叉验证】**。

### 1.2 三条人群轴（不要只按类型分，类型是最粗的轴）

**轴一：观影深度**

- **下饭型**（占比最大）：边吃边看，可倍速，手机刷。要的是"不费脑、不出戏"
- **陪伴型**：背景音，做家务时放着。要的是"随时能接上"
- **沉浸型**：关灯戴耳机，一集不落。要的是"值得专门花时间"
- **考据型**：会查设定、扒彩蛋。要的是"有东西可挖"

**轴二：口味阵营**（按情绪供给分，比按类型分更准）

- 爽感派（逆袭、复仇、打脸）
- 悬疑派（解谜、反转、烧脑）
- 情绪派（治愈、虐恋、亲情）
- 审美派（画面、表演、作者性）
- 猎奇派（设定新颖、脑洞、AI剧尝鲜）

**轴三：时间颗粒**

- 碎片 30 分钟（短剧、漫剧、单集剧）
- 整块 2 小时（电影）
- 长线追更（电视剧，周更/一次放出）

**组合出 4 个核心画像**（前两个是主攻，后两个是延展）：

| 画像               | 特征                                | 主推内容         | 平台倾向   |
| ---------------- | --------------------------------- | ------------ | ------ |
| **疲惫打工人**（主攻 1）  | 25–35 岁，下班 21:00 后，只想躺着。怕注水、怕烧脑过度 | 下饭剧、爽剧、短剧、漫剧 | 抖音、视频号 |
| **谨慎追剧党**（主攻 2）  | 有固定追剧习惯，被烂尾伤害过，看剧前必查分             | 长剧评测、横评、结局预警 | B站、小红书 |
| **AI剧尝鲜族**（延展 1） | 对新技术好奇，容忍度低但好奇心强，市场上几乎没有靠谱评测      | AI剧/漫剧实测     | 抖音、B站  |
| **周末仪式感**（延展 2）  | 每周固定看 1–2 部电影，看重审美和回味             | 单片深评、主题片单    | 小红书、B站 |

### 1.3 明确不做什么（定位的另一半）

- ❌ 不做全品类影视解说（红海，拼素材版权+文案功底，你打不过团队）
- ❌ 不做纯豆瓣搬运式打分（信息增量=0）
- ❌ 不做"高能名场面合集"（有版权风险，且不解决决策问题）
- ❌ 不做"每部都好看"的软文号（短期涨播放，长期归零）

### 1.4 你的独家武器（关键）

你已经有红果短剧/漫剧的抓数能力（热度榜、收藏数、评论、播放量、题材标签）。  
**大多数影视博主只有"我感觉"，你有"数据 + 我感觉"。** 这在两个地方能变成壁垒：

1. **AI剧 / 漫剧赛道**：几乎没有一个号在做正经评测，而这块内容量正在爆炸
2. **"数据说剧"栏目**：用热度曲线的形态讲一部剧是"高开低走"还是"慢热后爆"，别人做不出来

## 2. 推荐标准：把"我觉得好看"变成可复现的评分卡

### 2.1 评分卡（公开，固定 7 维，1–5 分）

| 维度       | 权重       | 打分口径                         | 观众真正关心    |
| -------- | -------- | ---------------------------- | --------- |
| **抓人度**  | 25%      | 第 1 集前 10 分钟能否建立"想知道后面"的钩子   | 我会不会看两集就弃 |
| **节奏密度** | 20%      | 有效剧情分钟 / 总时长。回忆、重复剪辑、无意义对话扣分 | 会不会水时长    |
| **逻辑自洽** | 15%      | 设定内部一致性、角色行为是否符合动机。硬降智即扣到底   | 会不会看出戏    |
| **情绪兑现** | 15%      | 爽点/泪点/笑点是否给到，承诺的爽感兑现率        | 能不能爽到     |
| **制作下限** | 10%      | 表演、服化道、剪辑是否低于"不出戏"阈值         | 有没有廉价感    |
| **独特价值** | 10%      | 有没有非它不可的看点（设定、结构、表演）         | 值不值得专门花时间 |
| **结局兑现** | 5%（强制标记） | 是否烂尾、是否强行圆满                  | 会不会白看     |

**分档规则**（总分→标签，每个标签必须在片子固定位置露出）：

| 总分      | 档位                 | 口播话术            |
| ------- | ------------------ | --------------- |
| ≥ 4.2   | **S 必看**           | "这两小时花得值，直接看"   |
| 3.4–4.2 | **A 可看**（必须标注适合场景） | "适合下班躺着看，别当正剧看" |
| 2.6–3.4 | **B 有空再说**         | "能看，但有你更该看的"    |
| < 2.6   | **C 劝退**（必须说清具体原因） | "第一集我就撤了，原因是……" |

### 2.2 止损线（你的招牌方法论，每条视频必给）

由"抓人度"倒推：**看到第 N 集还不行就撤**。

- 抓人度 5 分 → 第 1 集看完就够判断
- 抓人度 3 分 → 撑到第 3 集（很多剧第 3 集才立住）
- 抓人度 ≤2 分 → 前 15 分钟，不行就撤

这条规则做成**固定视觉符号**（比如进度条上的一个红色刻度），每期都出现。**重复到观众看到这个符号就想起你。**

### 2.3 避坑原则（红线，写进账号简介）

**内容红线（三不推）**

1. 没看完结局不推——如未看完，必须在画面上标注"我看完了前 X 集，结局未知"
2. 有硬伤的（降智、逻辑断裂、烂尾）必须单独标红提示，不能藏在"但整体不错"里
3. 付费点播、需要额外充值的，单独提示价格门槛

**剧透红线**

- 封面/标题/前 30 秒**零关键反转**
- 深度解析类内容必须标注剧透等级：🟢无剧透 / 🟡轻度 / 🔴重度（默认 🟢）
- 不使用结局画面做封面

**商业红线**

- 合作内容必须打标（"本片由 XX 提供观影"）
- 恰饭内容占比不超过当月内容的 **20%**，且不接"必须正面"的约
- 商单也照常给评分卡和止损线，不允许因为合作上调档位

### 2.4 评价维度：事实 / 判断 / 感受 三层分离

可信度的关键是**让观众能一眼分清哪句是事实、哪句是你**。

| 层             | 内容                                  | 呈现方式               |
| ------------- | ----------------------------------- | ------------------ |
| **事实层**（可核验）  | 平台、集数、单集时长、是否完结、豆瓣/IMDb 分、平台热度、播出时间 | 右上角固定信息卡（图形化，不用口播） |
| **判断层**（你的观点） | 评分卡各项得分、总档位、适合谁 / 不适合谁、止损点          | 口播 + 屏幕上打分动画       |
| **感受层**（观感）   | 一句话记忆点、名场面（不剧透版）、后劲、和哪部剧像           | 结尾 15 秒，情绪收尾       |

**这套三层分离的视觉化，本身就是差异化。** 90% 的影视号把事实、观点、恰饭混在一起说，所以你只要物理分开，观众立刻感到"这个号讲规矩"。

## 3. 视频形式与栏目规划

三层结构：**钩子层涨粉 → 信任层转化 → 深度层筑墙**。起步期不要全开，按第 5 节的节奏逐步上。

| 栏目        | 层   | 时长         | 频率       | 核心交付                       | 目的       |
| --------- | --- | ---------- | -------- | -------------------------- | -------- |
| **今晚看什么** | 钩子  | 60–90s 竖屏  | 每周 3–4 条 | 单剧：一句钩子 + 档位 + 止损点 + 一句劝退  | 算法推荐、涨粉  |
| **剧荒急救包** | 钩子  | 3–5min     | 每周 1 条   | 按场景/情绪的 5 部片单（"加班回家只想躺着看"） | 收藏、分享    |
| **看到第几集** | 信任  | 3–4min     | 每周 2 条   | 前 N 集实测拆解 + 弃剧点复现          | 建立"真看过"  |
| **同题材横评** | 信任  | 6–10min 横屏 | 每两周 1 条  | 3–5 部对比，讲清"选哪部取决于你哪种人"     | 搜索长尾、精准粉 |
| **为什么值得** | 深度  | 10–15min   | 每月 1–2 条 | 单剧深剖：结构、表演、作者意图            | 壁垒、铁粉    |
| **AI剧雷达** | 差异化 | 90s–3min   | 每周 1–2 条 | AI剧/漫剧新品实测 + 数据佐证          | 抢空白赛道    |

### 3.1 各栏目的固定结构（模板化，才能批量化）

**《今晚看什么》90 秒模板**

1. 0–5s｜钩子：直接抛结论（"这部别当爽剧看，当家庭片看"）
2. 5–20s｜一句话是什么 + 信息卡出现
3. 20–50s｜两条推荐理由（具体到情节功能，不喊口号）
4. 50–70s｜一条劝退（必须具体：谁别看、哪里崩）
5. 70–90s｜档位 + 止损点 + 关联推荐（"喜欢 XX 的可以看"）

**《看到第几集》模板**

- 不评好坏，只讲"信息分布"：第几集给钩子、第几集开始注水、第几集翻盘
- 用时间轴图形呈现，观众可以直接对号入座"我看到第 5 集觉得无聊是正常的"

**《同题材横评》模板**

- 开头先给决策树："你是要爽的看 A，要烧脑的看 B，要审美的看 C"
- 中间按同一把尺子对比（用评分卡的 3 个核心维度）
- 结尾给"如果只能选一部"

### 3.2 平台适配（同一内容，不同剪法）

| 平台  | 形态             | 优势              | 注意              | 建议角色        |
| --- | -------------- | --------------- | --------------- | ----------- |
| 抖音  | 60–90s 竖屏 + 合集 | 流量池大，短剧用户高度重合   | 完播率压力大，前 3 秒定生死 | **主阵地（拉新）** |
| B站  | 5–15min 横屏     | 深度内容容忍度高，粉丝粘性强  | 冷启动慢，需要长期养      | **主阵地（沉淀）** |
| 小红书 | 图文片单 + 短横评     | 搜索长尾强，女性向口味内容吃香 | 视频权重低，图文才是主力    | 承接搜索（低成本）   |
| 视频号 | 60–180s        | 家庭场景、中年用户       | 商业化弱，互动差        | 分发（顺带）      |

**起步建议**：抖音 + B站 双主阵地，小红书用图文搬运（同选题改写，15 分钟一条）。不要一开始铺四个平台。

## 4. 选题来源与持续更新机制

### 4.1 五条选题管道

| 管道       | 具体来源                                 | 更新频率       | 产出                |
| -------- | ------------------------------------ | ---------- | ----------------- |
| **排播日历** | 平台新剧定档表、影院上映表、短剧平台上新                 | 每周一固定 1 小时 | 本周候选 10–15 部      |
| **榜单数据** | 豆瓣口碑榜/新片榜、猫眼/云合热度、红果热度榜（**你已有抓取能力**） | 每周         | "高热度但没人好好评"的空白剧   |
| **需求反推** | 评论区"求推荐"、搜索下拉词、豆瓣小组/贴吧抱怨帖            | 持续         | 真实问题库（最好的选题都在这）   |
| **竞品缺口** | 头部号已评哪些、哪些被忽略                        | 每周         | 差异化选题（避开撞车）       |
| **自有片单** | 个人观影记录、相似度推荐                         | 持续         | 关联推荐（"喜欢 X 的看这部"） |

### 4.2 选题池（用一张表管住，状态机驱动）

|         |     |     |     |      |      |     |      |     |     |      |        |
| ------- | --- | --- | --- | ---- | ---- | --- | ---- | --- | --- | ---- | ------ |
| 字段：\`剧名 | 类型  | 平台  | 上线日 | 热度数据 | 我的档位 | 止损点 | 拟用栏目 | 状态  | 排期  | 发布链接 | 数据复盘\` |

状态流转：`候选 → 待看 → 已看（已评分）→ 已排期 → 已发布 → 已复盘`

**规则：进入"已看"的剧才能进排期。** 这条规则能防止你被热点裹挟去做没看过的剧。

### 4.3 生产节流（这是能不能"稳定更新"的真正瓶颈）

不是选题不够，是**看剧的时间不够**。三个解法：

1. **批量看、批量录**：集中一天看 3 部（每部看关键段落 + 快进扫全片），攒够 5 部素材再一次性录 5 条。切换成本远低于一部一录。
2. **库存保底 2 周**：永远有 6–8 条成品在库里。断更比更新慢伤害大得多。
3. **分级投入**：钩子层看 1 集 + 快进即可；信任层必须真看完；深度层才做全片精读。**别用深度的成本去做钩子层的内容。**

### 4.4 冷启动期的选题策略（前 30 条的关键）

**不要追爆款，追搜索型需求。**

理由：

- "XX 剧好看吗""XX 剧结局是什么"这类长尾搜索，流量稳定、意图精准、竞争小
- 你能在搜索结果里占位，长期被动获客
- 而追爆款是在和百万粉的号抢同一个推荐池，赢面极小

具体做法：前 30 条里至少 20 条对准「**有热度但还没人认真评的剧**」——用你的红果数据正好能批量找出来。

## 5. 可信度与差异化

### 5.1 可信度六件事（缺一件，观众就会怀疑你收钱）

| 动作        | 具体做法                              | 效果             |
| --------- | --------------------------------- | -------------- |
| 1. 公开评分卡  | 置顶视频专门讲一次"我怎么打分"，画面挂权重表           | 判断有依据，不是情绪     |
| 2. 公布弃剧点  | 每条都给"第几集该撤"，且讲清楚原因                | **可验证的"我真看过"** |
| 3. 主动说缺点  | 缺点要具体（"第 7 集后男主智商掉线"），不用"略有瑕疵"糊过去 | 显得诚实，且更专业      |
| 4. 纠错机制   | 评错了公开复盘（"上次我说这部不行，看到第 8 集我改口"）    | 反向增强信任         |
| 5. 商业披露   | 合作打标 + 占比上限 20%                   | 长期饭票的前提        |
| 6. 保持负评比例 | 20–30% 的内容是"劝退/别看"                | 一个只会夸的号，夸也没有分量 |

**最强的一招**：定期做「**本月我劝退了哪 5 部**」。这是纯逆向内容，涨粉效率低但信任效率极高，而且几乎没人做。

### 5.2 四条差异化（按可执行性排序）

1. **数据 + 人工双轨**（你现在就能做）  
   用红果/平台数据讲"热度曲线形态"：高开低走型、慢热后爆型、纯靠投流型。观众第一次看到"用数据说剧好不好看"，记忆点极强。
2. **AI剧 / 漫剧专门赛道**（最大机会）  
   这块内容正在爆发但评测几乎空白，你有数据 + 有看片量，可以先占位。风险是赛道本身可能不稳，所以作为第二曲线而非主线。
3. **"止损线"符号化**（最容易被记住）  
   固定的话术 + 固定的视觉符号 + 固定的位置。让观众形成条件反射："哦这个是那个告诉你看到第几集就撤的号"。
4. **口味坐标推荐**（复购率的来源）  
   "喜欢《XX》的会喜欢这部，讨厌《YY》的千万别看"。用相似度做推荐，比按类型推荐精准得多，且天然带"懂我"的情绪。

### 5.3 一条容易被忽略的差异化：**给"该不该看"以外的第二答案**

很多观众不是要"看什么"，是"**我不想动脑，给我个能放着的东西**"。所以除了"推荐好剧"，你还应该有一条产品线：  
**"不用看也能跟人聊"的内容**——3 分钟讲完一部剧的核心 + 值不值得补。这类内容播放量通常远高于深度评测，是涨粉主力，而深度内容负责沉淀。

## 6. 阶段性行动建议

| 阶段           | 周期        | 目标           | 关键动作                                                         | 通过标准（达不到就别进下一阶段）                           |
| ------------ | --------- | ------------ | ------------------------------------------------------------ | ------------------------------------------ |
| **0 定位打磨**   | 第 1–2 周   | 把定位写成一句话     | ①写定位卡（人群/场景/交付物/依据）②定死评分卡和止损线规则 ③做 3 条样片（1 个钩子+1 个信任+1 个差异化） | 找 10 个目标观众看样片，能复述出"这个号是干嘛的"                |
| **1 模型验证**   | 第 3–8 周   | 找到能跑的内容模型    | 30 条：3 种形式各 10 条；同题材做 3 组对照测试                                | 至少 2 条播放超均值 3 倍；完播率 > 35%；有 10 条以上评论说"求更多" |
| **2 栏目化**    | 第 9–16 周  | 稳定更新 + 涨粉    | 固定 3 个栏目（今晚看什么 / 看到第几集 / 剧荒急救包），周更 4–5 条；建选题池 + 2 周库存        | 粉丝破 5000；连续 8 周不断更；单条均播稳定                  |
| **3 深度与壁垒**  | 第 17–24 周 | 从"有用"到"非你不可" | 上"为什么值得"长视频 + "同题材横评"；开"数据说剧"；做一次"本月劝退 5 部"                  | 出现主动二创/被搬运；有粉丝催更特定栏目                       |
| **4 商业化与扩张** | 第 25 周起   | 变现 + 矩阵      | 接洽平台/片方合作；考虑小号（AI剧专项）或矩阵号                                    | 商单稳定且占比 <20%；单条商业内容不掉粉                     |

### 起步期最该避的四个坑

1. **一上来就做深度长视频**——没有粉丝基础，长视频完播率极低，算法不给量。先短后长。
2. **追求"每部都覆盖"**——影视内容无限，你的时间是有限的。宁可做 1/10 的剧但做透。
3. **被热点牵着走**——追热点会让你做没看过的剧，一旦被抓到"云评测"，信任归零。**宁可慢一天，也要真看完。**
4. **不敢说难听话**——初期容易怕得罪人。但你唯一的护城河就是"敢说"，怕了就没有存在理由了。

## 7. 需要哥哥先定的三件事

这三件事会改变方案的具体执行，先定下来再动手：

1. **主阵地选哪个？** 建议抖音（拉新）+ B站（沉淀）双开，小红书图文顺带。
2. **出镜/露脸吗？** 露脸信任建立快 3 倍，但产能受限；不露脸可以用"信息卡 + 图形化 + 配音"做，产能高。**建议先不露脸跑通模型，验证后再决定。**
3. **每周能投入多少小时？** 决定栏目开几个。≤8 小时：只做钩子层（周 3 条）；8–15 小时：钩子+信任层；≥15 小时：全开。
