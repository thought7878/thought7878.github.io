
> 配套技能：`short-drama-detail-page`（又名 `短剧-动画视频`，两者内容一致）。
> 目标：给定一部短剧的原稿、配音与字词时间戳，生成 1080×1920 竖屏详情页 HTML（带对齐配音的入场动画）、多风格选型、静态预览图与动画成片视频。

---

## 一、输入文件

一部短剧一个目录，至少包含前三项：

| 文件 | 必需 | 说明 |
|---|---|---|
| `原稿.md` | 是 | 字段文案 + 显示/隐藏批注（HTML 注释形式） |
| `字词时间戳.json` | 是 | 字/词/语段级时间轴，动画触发时刻来源 |
| `配音.wav` | 是 | 口播音轨，页面预览与成片音轨 |
| `配音稿.md` | 否 | 口播全文，用于核对、精简文案 |
| `字幕.srt` | 否 | 素材视频叠加成片时烧录用 |

### 原稿.md 字段

`剧名 / 类型 / 题材 / 集数 / 内容简介 / 核心看点 / 适合人群 / 综合评分`。

批注口径（写在 HTML 注释里）：

| 字段 | 页面处理 |
|---|---|
| 剧名 | 显示；先居中淡入，说到第二句开头时上移到顶部第一行 |
| 类型 / 题材 / 集数 | 字段标题不显示，仅显示内容；三者一行胶囊排列 |
| 内容简介 / 核心看点 / 适合人群 | 标题显示，正文在透明圆角框内 |
| 综合评分 | 标题不显示；仅“数字+分”大字置右上角，不挤压剧名 |

### 时间戳 JSON 关键字段

`duration_sec`（总时长）、`segments`（语段 `{text,start,end}`）、`chars`（单字 `{char,start,end}`）。触发时刻优先取语段起点；看点各条再按“一是/二是/三是”在单字流中定位。

## 二、环境前置

- 本机已装 **Chrome**（截图/录帧用无头模式）与 **ffmpeg / ffprobe**（合成视频）。
- Playwright 在本机存在 libc++ 兼容问题，**不要使用**，截图一律走 Chrome 无头 CLI。

## 三、标准流程（五步）

以下命令中 `<短剧目录>` 替换为该剧文件夹的绝对路径；脚本位于技能目录 `scripts/` 下。

### 第 1 步：解析输入，生成结构化数据

```bash
python3 scripts/analyze_drama.py <短剧目录>
```

产出 `<短剧目录>/page_data.json`：字段文案、显隐批注、对齐后的时间轴。

### 第 2 步：人工修订 page_data.json（关键）

自动解析只做初稿，构建前必须核对：

- **精简文案**：按 `配音稿.md` 压缩简介；看点拆成 `head`（2–6 字小标题）+ `text`（一句正文），不写序号。
- **核对时间轴**：对照配音语感确认 `timeline` 各触发时刻；晚到/提前的直接改秒数。
- **确认显隐**：按 `原稿.md` 批注核对各字段是否显示。

`page_data.json` 主要结构：

```jsonc
{
  "title": {"line1": "…，", "line2": "…", "line3": "第四季", "full": "…"},
  "type": "漫剧", "genre": "脑洞·穿越·系统", "ep": "194集",
  "synopsis": "……",
  "points": [ {"head": "反套路爽", "text": "……"} ],
  "audience": "……",
  "score": "94",
  "timeline": {
    "titleFade": 0.27, "titleMove": 1.47, "titleMoveDur": 0.70,
    "meta": [ {"id": "metaType", "at": 4.47} ],
    "synopsis": 11.25, "pointsHead": 18.90,
    "points": [ {"id": "point1", "at": 20.67} ],
    "audience": 39.66, "score": 49.65, "duration": 52.0
  },
  "audio": "配音.wav"
}
```

### 第 3 步：渲染主页面 + 静态预览

```bash
python3 scripts/build_page.py <短剧目录> --theme A_黑金极简 --out 详情页.html
python3 scripts/screenshot.py <短剧目录>/详情页.html
```

- 截图默认输出同目录 `详情页_静态预览.png`（1080×1920 最终态）。
- 浏览器打开 HTML：
  - 加 `?preview=1` 呼出“播放预览”按钮，空格键播放/暂停，试听动画与配音是否对齐；
  - 加 `?t=秒数` 直接渲染指定时刻，用于逐段校验。

### 第 4 步：多风格选型（需要时）

```bash
python3 scripts/make_themes.py <短剧目录>
python3 scripts/screenshot.py <短剧目录>/风格方案/*.html
```

产出 `风格方案/` 下六版 HTML + `index.html` 对比索引页。选定编号后，用第 3 步命令加 `--theme <编号>` 落地主页面。

### 第 5 步：合成动画成片

```bash
python3 scripts/render_video.py <短剧目录>/详情页.html --out 详情页_动画成片.mp4 --fps 24
```

流程：按帧率逐帧以 `?t=` 渲染截图 → ffmpeg 拼帧 → 封装配音音轨（`libx264 / yuv420p / aac 192k`，以音频时长截断）。

- 预览阶段可用 `--fps 12` 省时间；成片用 24/30。
- `--duration` 可手动指定时长；默认取 `page_data.json` 的 `timeline.duration`，缺失时用 ffprobe 读音频。

> 若已有实拍/素材视频，需要在画面上叠加文字、烧录字幕，走 ffmpeg `drawtext` / `subtitles` 方案（文本走 textfile 规避转义，字体 `/System/Library/Fonts/PingFang.ttc`），不使用本技能的录帧脚本。

## 四、页面设计规范

### 画布与安全区

- 固定 **1080×1920（9:16）**，`overflow: hidden`。
- 顶部留 130px 避让状态栏/导航；左右边距 80px，关键文字不压右侧互动按钮列。
- 底部预留约 300px 给账号文案、音乐条、烧录字幕；主体内容止于 y≈1600。

### 信息层级（自上而下）

1. 右上角评分（仅数字大字 +“分”，无“综合评分”标题）
2. 剧名三行：主句两行 + 季数一行（小字、宽字距、弱化色）
3. 类型 / 题材 / 集数：一行三枚胶囊，间距 24px，标签文字不出现
4. 内容简介（小标题 + 透明圆角框正文）
5. 核心看点（小标题 + 透明圆角框，条目逐条排列）
6. 适合人群（小标题 + 透明圆角框正文）

### 已定稿的样式决策（沿用，勿回退）

- 不放品牌角标/Logo、不放 pill 前 emoji、不放底部频道条与标语；无装饰底纹与背景大字。
- 胶囊统一透明深底（亮底主题用半透白）+ 细描边，`border-radius: 999px`；不做实色块，不用竖线分隔。
- 正文框：半透底 + 细描边 + 28px 圆角，不用实色大卡片。
- 剧名三行同一标题色，不做句中高亮变色；看点条目小标题可用强调色加粗。
- 看点不显示 01/02/03 序号；题材分隔符用 `·`。

### 动画规格

| 元素      | 入场方式                                             | 缓动                                | 时长       |
| ------- | ------------------------------------------------ | --------------------------------- | -------- |
| 剧名      | `titleFade` 淡入；`titleMove` 起由居中平移到顶部，缩放 1.05→1.0 | 淡入 easeOutCubic；位移 easeInOutCubic | 位移 0.70s |
| 三枚胶囊    | 依次淡入 + 上移 24px                                   | easeOutBack（回弹）                   | 0.35s    |
| 简介 / 人群 | 淡入 + 上移 30px                                     | easeOutCubic                      | 0.40s    |
| 看点标题    | 淡入                                               | easeOutCubic                      | 0.35s    |
| 看点各条    | 依次淡入 + 右移 40px 滑入                                | easeOutCubic                      | 0.35s    |
| 评分      | 右上角回弹缩放 0.6→1.0                                  | easeOutBack                       | 0.40s    |

页面内置录帧接口：`window.__render(t)` / `window.__setT(t)`，按秒数直接渲染，不依赖音频播放。

## 七、常见问题

- **截图没产出**：先确认 Chrome 路径；`CVDisplayLinkCreateWithCGDisplay failed` 是可忽略告警，只要 PNG 生成即成功。
- **ffmpeg 滤镜报错**：中文/空格路径下，命令以媒体目录为 cwd，文件名传相对路径；文本叠加走 textfile，避免转义问题。
- **录帧很慢**：每帧一次 Chrome 冷启动，帧率越高耗时越长；预览降到 12fps，成片再提高。
- **时间轴对不上口播**：直接改 `page_data.json` 里对应 `at` 秒数，重新渲染即可，不用改模板。
- **想加新风格**：在 `themes.py` 的 `THEMES` 追加一组颜色/字体/装饰字段，无需改模板与主流程。
