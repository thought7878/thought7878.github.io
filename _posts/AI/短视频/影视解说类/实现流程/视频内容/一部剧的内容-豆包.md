# 短剧介绍内容要素清单（短视频平台版）

结合你「选片官／鉴剧人」的人设，下面按**优先级**分三层：视频口播要素、配套文案要素、不同品类的差异化补充。

## 一、视频口播要素（按成片时间轴排序）

### 1. 前 3 秒钩子（必做，决定完播率）

任选一种切入：

- **背书型**：高分／爆款／黑马，如"这部 8.5 分的 AI 剧，我一口气刷完"
- **悬念型**：抛核心冲突或反常设定，不给答案
- **反差型**：低成本逆袭、题材反套路、名场面切片
- **提问型**：对准目标观众，如"喜欢逆袭爽剧的别划走"

### 2. 作品基础档案（信息要全，方便观众检索）

- 片名（含别名／原名）
- 品类：AI 剧／漫剧／真人短剧
- 题材标签：甜宠、逆袭、悬疑、战神、穿越、复仇、治愈等
- 体量：集数、单集时长、更新状态（完结／连载中）
- 播出平台／来源

### 3. 口碑与热度背书（增强可信度）

- 评分、榜单排名、热度数据
- 弹幕／评论区高频反馈、爆款标签
- 同类型对标作品（如"某某赛道又一部黑马"）

### 4. 剧情简介（守住无剧透红线）

- 背景设定 → 主角处境 → 核心冲突 → 故事走向
- 只讲开篇和主线驱动力，**不透结局、关键反转和隐藏身份**
- 用一句话能说清的"爽点引擎"（如被退婚后开挂、真假千金互换）

### 5. 核心看点（提炼 3–5 个，是内容主体）

- **人设**：主角魅力、反派塑造、CP 关系
- **情绪点**：爽点、泪点、燃点、反转、名场面／名台词
- **制作亮点**：画面质感、节奏、配音、配乐、特效（按品类取舍）
- **差异化**：与同类剧相比独有的东西

### 6. 鉴剧人主观点评（你的人设核心，区别于搬运号）

- 个人推荐理由和综合评分
- **适合人群**：爱看什么的观众会喜欢
- **避雷提示**：槽点、短板、不适合谁看（客观说缺点反而提升信任）

### 7. 行动引导（转化收尾）

- 观看渠道、追更建议（一次性刷完／蹲更新）
- 引导点赞、收藏、关注频道，预告下一部测评

## 二、配套文案要素

| 位置    | 需要包含的内容                          |
| ----- | -------------------------------- |
| 标题    | 钩子 + 关键词（品类／题材）+ 情绪词，控制在平台推荐字数内  |
| 封面大字  | 1 个最强卖点或评分，一眼可读                  |
| 简介正文  | 一句话定位 + 3 条看点 + 观剧提示 + 基础档案      |
| 话题标签  | 品类词（AI 剧／漫剧／短剧）+ 题材词 + 剧名 + 赛道热词 |
| 评论区预埋 | 补充槽点、答疑（在哪看／多少集）、引导互动提问          |

## 三、按品类补充的专属看点

- **AI 剧**：画面生成质量、世界观脑洞、特效与场景、AI 配音表现、技术完成度
- **漫剧**：画风与分镜、改编来源（小说／漫画）、配音演绎、动态效果
- **真人短剧**：演员表现与颜值、服化道、节奏快慢、名场面实拍质感

## 四、几条原则

- **无剧透**：简介只给到"冲突建立"，结局和反转留给正片
- **信息密度前置**：前 10 秒内交代片名、品类、评分、一句话看点
- **真实克制**：评分和数据要有出处，避雷点不回避，维持鉴剧人可信度
- **合规注意**：切片使用控制时长、避免大段搬运，文案不夸大宣传
