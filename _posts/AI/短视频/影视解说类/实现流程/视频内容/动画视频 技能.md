## 技能结构

```
short-drama-detail-page/
├── SKILL.md                      # 工作流入口与脚本一览
├── assets/
│   └── detail_template.html      # 1080×1920 通用模板（占位符 + 时间轴渲染引擎）
├── scripts/
│   ├── analyze_drama.py           # 解析 原稿.md + 字词时间戳.json → page_data.json
│   ├── build_page.py              # 数据 + 模板 + 主题 → 单页 HTML
│   ├── make_themes.py             # 批量生成 A–F 六版 + 对比索引页
│   ├── screenshot.py              # Chrome 无头截图（支持 ?t= 定位时刻）
│   ├── render_video.py            # 逐帧录帧 + ffmpeg 合成竖屏成片（封配音）
│   └── themes.py                  # 六套主题色板（可追加新主题）
└── references/
    ├── input-format.md           # 输入文件 Schema、批注显隐规则、page_data 结构
    ├── design-rules.md            # 安全区、精简原则、动画缓动规格、已沉淀决策
    └── themes.md                  # 六套主题氛围与适用场景
```

## 固化下来的关键规则

- **输入**：`原稿.md`（文案+显隐批注）、`字词时间戳.json`（字/语段时刻）、`配音.wav`、`配音稿.md`（核对文案）
- **时间轴**：剧名居中淡入 → 说到第二句平滑上移顶部；胶囊/简介/看点/人群/评分按配音时刻依次入场，缓动与时长沿用本次定稿
- **设计约束**：透明胶囊、透明圆角正文框、剧名同色、看点无序号、无多余图标角标；安全区与底部避让已写进模板
- **两条成片路径**：HTML 录帧合成纯页面动画视频；素材视频叠加文字走 ffmpeg drawtext/subtitles
