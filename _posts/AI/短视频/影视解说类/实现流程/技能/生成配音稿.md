## 怎么用

最省事的用法是直接说需求，不需要你记忆路径。在新会话里说“技能：生成配音稿，工作目录 xxx”，或直接说“把 `脚本.md` 排成配音稿”“配音稿校对一下”，都会触发技能；描述里写了触发词，技能会自动加载。

完整一轮的流程如下：

1. 把 `脚本.md`（有 `读法规则.md` 一起）放进本期目录，例如 `2026-11-23/`。
2. 说一句话：“按生成配音稿流程处理这期”。
3. Agent 会产出 `配音稿.md`，并在 `工程/01_配音交付/用字替换表.tsv` 登记所有改动（脚本会在这两个位置自动找表：工作目录根、`工程/01_配音交付/`）。
4. 它会自己跑校验；五项全部 PASS 才会告诉你可以合成：

```
A 字长偏差 ≤ 表内次数      B 部序与四块计数
C 差异全部能归到表        C2 符号转写无残留
D 易字音序相等            D2 已核词没被误改
E 字幕文件无易字泄漏
```

你也可以手动执行：

```
SKILL="/Users/ll/Library/Application Support/Doubao/Default/.doubao/agent_mode/workspace/.user_skills/生成配音稿"
python3 "$SKILL/scripts/查读音.py" 少夫人 弹幕 数剧   # 改之前先看默认读音
python3 "$SKILL/scripts/骨架校验.py" /Users/ll/Desktop/资料/视频博主/制作文件夹/2026-11-23
```

**这个技能内置了这次遇到的问题及其处理规则**

- 硬规则第 1 条：默认读音正确的不许改，`弹幕 dàn`、`数剧 shù` 写进“已知词条”，D2 项会阻止“过度纠正”。
- 硬规则第 3 条：配音稿只给 TTS，字幕字形从 `脚本.md` 走，别再造第二份字幕稿。
- `查读音.py` 会把多音字逐个标出来（如 `少:shao3/shao4`），避免你再次凭印象判断。
- `骨架校验.py` 的部数与块计数是按脚本动态算的，不只限于 10 部，以后做 12 部、8 部照样能校验。
