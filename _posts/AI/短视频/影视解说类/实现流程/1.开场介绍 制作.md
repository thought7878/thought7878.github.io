## 字幕位置
字幕改为绝对定位居中（中心位置固定），底部距离调整为 108px。

>对于1920×1080分辨率（16:9）的视频，字幕应放置在距离视频底部多远的位置比较合适？请给出推荐的像素距离或底部安全边距的百分比，说明该数值的依据（如画面构图、电视台/流媒体安全区规范），并说明在不同播放设备和平台上的注意事项。

**结论：1080p 视频字幕底部边距推荐 80px（约 7.4%），下限 54px，要上短视频平台就提到 108–162px。**

### 推荐数值

| 场景               | 底部边距                  | 占高度比例        |
| ---------------- | --------------------- | ------------ |
| 通用下限（标题安全线）      | ≥ 54px                | 5%           |
| **通用推荐值**        | **72–*108*px，取 80px** | **6.7%–10%** |
| 短视频平台分发（抖音/快手横屏） | ≥ 108px，稳妥 162px      | 10%–15%      |

### 依据

1. **广电/流媒体安全区规范**：EBU R95 和 SMPTE HD 规范把“标题安全区（title-safe）”定为画面四周各收进 **5%**——1080p 即 54px。字幕属于文字信息，必须完整落在标题安全区内，54px 是硬下限。老式的“动作安全 90%/标题安全 80%”是 4:3 CRT 时代留的余量，高清/流媒体时代已放宽为 93%/90%。
2. **构图**：字幕贴死底边会显得“坠”，留 5–10% 的呼吸感更舒服；同时这个高度接近视线下三分之一构图线，视觉重心自然，不遮挡主体。
3. **可读性**：字幕太低会被播放器 UI 或电视过扫描裁掉，太高又会压住人物/主体。

### 设备与平台注意事项

- **电视端**：部分老电视/机顶盒仍有 1–3% 过扫描裁切，54px 下限就是为这个留的；新电视基本无此问题。
- **YouTube / B 站 / 西瓜（横屏播放为主）**：底部主要是进度条和全屏按钮，鼠标悬停才出现，80px 完全安全。B 站弹幕在上部，不影响。
- **抖音 / 快手 / 视频号（横屏素材被竖屏 Feed 播放）**：这是最容易翻车的场景——底部会被平台的文案区、进度条、互动按钮**固定遮挡约 15%（≈162px）**，右侧还有点赞/评论按钮列。如果成片要发抖音，字幕底部边距按 **162px 以上**排，或者干脆给竖屏单独出一版（1080×1920，字幕放在中部偏上）。
- **Netflix 等专业流媒体**：其制作规范要求字幕底边距画面底部约 5%，与上面一致；多行字幕时整个字幕块都要在线内。
- **移动端横屏播放**：iOS 有底部 Home 指示条/手势区，播放器 UI 遮挡更多，边距越靠上限越稳。

**对照你的项目**：开场动画里字幕用的 `bottom: 64px`（720 舞台坐标系），换算到 1080p 是 **96px ≈ 8.9%**——正好落在推荐区间里，不用改。要发抖音的话需要把字幕上移到 162px 以上（720 舞台即 108px），说一声我就调。
