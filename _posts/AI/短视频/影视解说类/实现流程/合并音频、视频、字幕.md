# 合成视频脚本说明（合成视频.py）

> 更新日期：2026-11-06 ｜ 脚本路径：`制作文件夹/合成视频.py`

## 一、概述

`合成视频.py` 是一个基于本机 ffmpeg 的本地合成脚本，用于短剧解说视频的最终封装：

- **输入四件套**：`配音.wav`（音轨）、`字词时间戳.json`（字/词级时间戳）、`字幕.srt`（字幕）、文件名含 `_无音轨无软字幕` 的视频（画面）。
- **输出成片**：带中文配音音轨、左上角逐条淡入的信息文字、底部烧录字幕的视频文件。
- **自动化**：信息条目（剧名/集数/热度/类型/评分）从时间戳 JSON 自动提取，触发时间自动对齐音频时间轴，无需手工打点。
- **实测环境**：macOS + `/usr/local/bin/ffmpeg`（含 libass、libfreetype、libx264）。

## 二、核心要点

### 2.1 输入定位

- 接收**目录**或**目录内视频文件**作为输入路径，脚本自动在同目录查找四类文件。
- 缺任一必需文件立即报错退出（退出码 1），并给出缺失文件完整路径。

### 2.2 左上角信息叠加（淡入动画）

- 每条信息一个 `drawtext` 滤镜，淡入由 alpha 表达式驱动：
  ```
  alpha='if(lt(t,START),0,if(lt(t,START+FADE),(t-START)/FADE,1))'
  ```
  `START` 为触发词在音频中的出现时间，`FADE` 为淡入时长（默认 0.8s）。
- 文字出现后**保持显示至视频结束**，按出现顺序在左上角逐行堆叠。
- 文本经 `textfile=` 临时文件传入，规避 drawtext 的中文/特殊字符转义问题；临时文件在合成结束后自动清理（`--keep-temp` 可保留）。
- 内置规则定义在脚本顶部 `OVERLAY_RULES`，可直接编辑：

| 条目  | 触发方式       | 提取内容             | 实测示例                    |
| --- | ---------- | ---------------- | ----------------------- |
| 剧名  | `《...》` 定位 | 书名号内文字           | 0.66s《重生丑小鸭逆袭成了万人迷 第五季》 |
| 集数  | 触发词「共」     | 「共…集」间中文数字→阿拉伯数字 | 3.72s 共260集             |
| 热度  | 触发词「热度」    | 后续中文数字（含万/亿换算）   | 4.98s 热度：9126万          |
| 类型  | 触发词「属于」    | 「属于…题材」间标签       | 6.90s 类型：脑洞 · 重生 · 系统   |
| 评分  | 触发词「综合评分」  | 后续中文数字           | 31.52s 综合评分：88          |

- 某条信息定位失败时**跳过该条并警告**，不中断合成。

### 2.3 字幕处理

- 使用 `subtitles` 滤镜（libass）烧录，`force_style='Alignment=2,...'` 固定**底部居中**。
- 默认样式：`Alignment=2,FontSize=16,Outline=1,MarginV=20`（FontSize 为 ASS 单位，相对 288 行脚本高度），可用 `--subtitle-style` 整体覆盖。

### 2.4 音视频封装

- 视频重编码 libx264（CRF 18 / preset medium / yuv420p），音频 aac 192k / 44100Hz。
- **时长规则（默认）**：视频长于音频时，以音频时长截断视频（`-shortest`）；保留完整视频长度用 `--keep-full-video`。
- 输出带 `+faststart`，便于在线播放秒开。

### 2.5 路径与转义

- ffmpeg 以**媒体所在目录为工作目录**运行，文件均用裸文件名引用，规避中文/空格路径在滤镜中的转义问题。
- 临时 drawtext 文本写入媒体目录下的 `_compose_xxx/` 子目录，`finally` 中统一清理。

## 三、使用方法

```bash
# 基本用法（目录）
python3 合成视频.py '制作文件夹/测试/2_重生丑小鸭逆袭成了万人迷 第五季'

# 常用定制
python3 合成视频.py <目录> --font-size 32 --fade 1.0 -o 输出.mp4

# 先看命令不执行
python3 合成视频.py <目录> --dry-run
```

### 主要参数

| 参数                              | 默认值                                            | 说明                   |
| ------------------------------- | ---------------------------------------------- | -------------------- |
| `-o, --output`                  | 视频名去 `_无音轨无软字幕` + `_合成`                        | 输出路径                 |
| `--fontfile`                    | `/System/Library/Fonts/PingFang.ttc`           | 左上角文字字体              |
| `--font-size`                   | 视频高 ÷ 22                                       | 左上角字号                |
| `--fade`                        | 0.8 秒                                          | 淡入动画时长               |
| `--margin-x / --margin-y`       | 宽÷32 / 高÷32                                    | 信息区边距                |
| `--line-height`                 | 1.7                                            | 行距系数（相对字号）           |
| `--color / --border`            | white / 2                                      | 文字颜色 / 描边宽度          |
| `--subtitle-style`              | `Alignment=2,FontSize=16,Outline=1,MarginV=20` | 字幕 ASS 样式            |
| `--crf / --preset`              | 18 / medium                                    | x264 质量 / 预设         |
| `--keep-full-video`             | 关闭                                             | 保留完整视频长度（默认截断到音频时长）  |
| `--no-overlay / --no-subtitles` | 关闭                                             | 关闭信息叠加 / 字幕烧录        |
| `--dry-run`                     | 关闭                                             | 只打印 ffmpeg 命令        |
| `--keep-temp`                   | 关闭                                             | 保留 drawtext 临时文本（调试） |

## 四、错误处理

| 场景                             | 行为           | 退出码 |
| ------------------------------ | ------------ | --- |
| 输入路径不存在 / 缺文件 / 候选视频不唯一 / 字体缺失 | 报错并列出路径      | 1   |
| JSON 解析失败 / 时长读取失败 / 输出与输入同名   | 报错拒绝执行       | 2   |
| 时间轴超出音频时长、触发时间超出视频时长           | 警告（跳过该条）或提示  | 2   |
| ffmpeg 命令失败                    | 打印退出码与常见原因提示 | 3   |

信息条目提取失败（如书名号缺失、中文数字解析失败）只警告跳过，不中断整体合成。

## 六、注意事项与经验

|     |     |
| --- | --- |

1. **验证要看文件**：管道 `python3 xxx | tail` 会吞掉 Python 退出码，确认成功与否应检查输出文件是否存在。
2. **drawtext 的 textfile 是相对 cwd 解析的**：临时文本放在子目录时，滤镜里必须带上子目录相对路径。
3. **中文数字转换**：脚本内置 零~九/十百千/万亿 转换，覆盖「二百六十」「九千一百二十六万」这类表述；无法解析时跳过并警告。
4. **截断的 2 秒尾巴**：如需精确到帧，可加 `-force_key_frames` 或调 GOP，目前无实际必要。
5. **自定义信息条目**：直接编辑脚本顶部 `OVERLAY_RULES`，支持自定义触发词与显示格式（label 用 `{}` 占位数值）。
