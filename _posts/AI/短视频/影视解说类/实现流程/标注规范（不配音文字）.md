
## 不配音文字怎么标（标注规范）

### 统一原则：**标记 = 预填默认，人 = 最终仲裁**

标记的作用是把复核页上的默认勾选状态设对，不是跳过复核。任何标记在复核页上都可以被推翻，且**被推翻时写回 `decisions.json`，不改动稿子**。

### 三个记号

| 记号             | 语义                 | 流水线结局                |
| -------------- | ------------------ | -------------------- |
| 行首 `>`         | 给工作人员看的，不给人听的      | 默认**丢弃**             |
| 行首 `> @key: 值` | 旁注里带机器指令           | **不丢弃**，按 key 分流     |
| `【…】`          | 画面/剪辑旁注（独占一行 或 句中） | 按形态分两类处理，第三种形态报警（见下） |

不用 HTML 注释 `<!-- -->`：编辑器里默认隐藏，**作者看不见自己标了什么**，逐条确认这一步就废了，复制粘贴时还会丢失。也不用 `;;`/`%%` 这类自定义前缀：Markdown 不识别，渲染后与正文混成一片。

### `@key:` 指令集

| key       | 写法                           | 去向                              | 为什么不是丢弃                                 |
| --------- | ---------------------------- | ------------------------------- | --------------------------------------- |
| `@留白`     | `> @留白: 2s`                  | `gaps.json` → 本地 `anullsrc` 插静音 | 这是**时长**，删掉就丢了停顿                        |
| `@上屏`     | `> @上屏: 张三 / 创始人`            | `dropped.jsonl`，记 `kind:"上屏备查"` | **不丢弃到看不见**——这些字要在剪映里手打上屏，删干净了反而不知道漏了什么 |
| `@读法`     | `> @读法: 绿原酸=lv4 yuan2 suan1` | `hot_fix.pronunciation`         | 删了就读错了，这是最容易被误丢的一类                      |
| `@读法`（谐音） | `> @读法: NBA=恩比艾`             | `hot_fix.replace`               | 同上；字幕走原稿，谐音不上屏                          |
| `@语气`     | `> @语气: 这段压低点，别像念说明书`        | 该段 `instruction`                | 转成参数，不转成静音                              |
| `@备选`     | `> @备选 A: …` / `> @备选 B: …`  | **未选定则报错停止**                    | 默认丢或默认留都会静默选错，成片里最难发现                   |
| `@待写`     | `> @待写: 这里再补个行业数据`           | **未补齐则报错停止**（`kind:"占位未决"`）     | 念出来毁片、静默删掉毁稿，两个默认值都错，只能阻断               |

**`@待写` 是这套约定里唯一的"内容缺失"闸门**，和 `@备选` 的"多版本未挑"并列，都属于阻断类：`clean.py` 遇到它们**不设默认值、不进 spoken.txt、也不当旁注删掉**，而是让 `pipeline run` 直接失败退出。占位文本最危险的写法是不标——所以 `--lint` 还要自动扫正文里的 `待补 / 待写 / 待定 / 再想个 / TODO / TBD / XXX / ___ / ？？`，命中即同样阻断（词表按真实稿子调，宁滥勿漏，因为这里漏报的代价远大于误报）。

**BGM / 音效 / 剪辑标记不需要新 key**：这类文字（`BGM 起`、`音效：倒水声`、`淡出转场`）一律写成裸 `>` 旁注，默认丢弃且**不留白**——流程是文案先行、画面跟着配音剪，这些点在纯 TTS 音频里没有语音可让位，留白反而拖长成片。确实需要空一段出来给音效占位时，显式补一行 `> @留白: 1.5s`。`--lint` 对这批词做**高置信预选"删"**（不是低置信标黄），因为正文里几乎不会以"淡出转场"开头说话。

拼音一律写 **ASCII 数字声调**（`lv4` 而非 `lǜ`），与 `hot_fix` 文档示例 `tian1 qi4` 同形。裸 `>`（不含 `@`）= 纯旁注 → 安全默认丢弃。

### `【…】` 的两种确定形态 + 一种报警形态

| 形态 | 例 | 处理 |
|---|---|---|
| **独占一行** | `【画面】切实验室空镜` | 整行丢弃 |
| **句中** | `苦味在两周后达到峰值【切手冲特写】所以别囤豆。` | 只剥括号内容，前后句连读 + 一个短停顿 |
| **行首且后面还有正文** | `【主播】今天讲三件事。` | **报警问人，不自动剥**（用户确认稿中无说话人前缀习惯，见非目标表） |

第三种形态不实现自动剥离：没有这个习惯却有这个写法，多半是**忘了换行的旁注**或**临时改的强调**，猜错代价不对称。命中即进复核页**阻断区**，`run` 阶段未决则拒跑——和占位文本同一类处理。

同一对 `【】` 里的内容若确实要念（例如念出"【警告】"），在复核页勾"念"即可推翻，不需改稿。

### 完整例子

```markdown
# 为什么你的咖啡一直在变苦

> @留白: 2s
【画面】咖啡豆特写，慢速推近

【主播】咖啡变苦这件事，其实从你买到豆子那一刻就开始了。
烘焙度越深【切到手冲特写】苦味物质在两周后达到峰值。

> 备注：这段别像念说明书
> BGM 起，轻钢琴
> @读法: 绿原酸=lv4 yuan2 suan1
> @语气: 平稳，略微放慢
> @上屏: 苦味峰值 · 烘焙后第 14 天

所以真正的问题不是"怎么冲不苦"，而是"你买的是第几天的豆子"。

> @待写: 这里补一个烘焙日期分布的数据

> @备选 A: 下次买豆子，让店家告诉你烘焙日期。
> @备选 B: 记住一句话：烘焙日比保质期重要。
```

分流结果：`dropped.jsonl` = H1 + 备注 + BGM 行 + 一行 `kind:"上屏备查"` 的"苦味峰值 · 烘焙后第 14 天"（**不进 TTS、也不进字幕，只供剪辑时手打上屏对着看**）；`gaps.json` = 一个 2000 ms；`hot_fix.json` = `{"pronunciation":[{"绿原酸":"lv4 yuan2 suan1"}]}`；该段 `instruction` 追加"平稳，略微放慢"。

**但这份稿子此刻跑不出音频**——`pipeline run` 会先失败退出，报 3 个未决项：`@待写` 未补齐、`@备选 A/B` 未选定、`【主播】` 命中"行首且有正文"的报警形态。人工补齐/勾选后 `spoken.txt` 才编译得出来（此时正文句子 = 3 句，`【主播】` 与 `【切到手冲特写】` 的处理结果取决于人怎么选）。

### 没有标记的老稿：扫描分级（同一套默认值的另一来源）

信号按置信度排序，界面降序排列，**高置信预选"删"、低置信预选"留"，人只改反常的十几条而不是通读全文**——这是把"逐条确认"做轻的唯一办法。

| 级 | 信号 | 默认建议 | 依据 |
|---|---|---|---|
| **标记** | 行首 `>`、`@key:`、`【】` 三种位置 | 按上表精确分流 | 新稿路径，零歧义 |
| 高 | `#` 标题、`|` 表格、``` 代码块、`![]()`、`<!-- -->` | **删** | Markdown 结构，几乎不可能是口播正文 |
| 中 | 老稿里的 `【…】`、`（…）`/`(…)` 内含画面动词、`[…]`、独占一行的 `**粗体**`、**独占一行的短指令行**（≤8 字且无句末标点，如 `BGM 起`/`淡出`/`切特写`/`音效：倒水`） | **删**，逐条看 | 中文脚本写旁注的常见习惯；老稿里这类词没有 `>` 包，只能靠"整行很短 + 无标点 + 含制作动词"三条件联合判，单靠词表会大量误伤正文 |
| 低 | 句中（不是整行）含 画面/镜头/空镜/转场/BGM/字幕/切/插入/此处/备注/提示/片头/片尾 | 只标黄，**默认留** | 会误伤正文（"这个镜头语言很关键"），必须人判 |
| — | 其余正文 | 念 | — |

同一对 `【】` 在**新稿**里是确定语义（标记级，按三种位置处理），在**老稿**里只是中置信建议（可能真是该念的强调词）——靠稿子里有没有任何 `@key:` 判定它属于哪一路，这个判定进 `rule_version` 一起哈希。

**防漏标 `clean.py --lint`（两类检查，代价不对称所以阈值不同）**：

1. **旁注漏标**：正文行（无 `>` 前缀）中出现"画面/镜头/切到/此处插入/BGM/空镜/淡入淡出"却没用 `>` 或 `【】` 包起来 → 报警。漏标的后果比误删严重得多：**它会真的被念进配音里，字幕还跟着错**。
2. **占位漏标**：正文行命中 `待补/待写/待定/再想个/举个例子/TODO/TBD/XXX/___/？？` → **升级为阻断项**，不是报警。理由同上但更硬：这里误报只是多点一次勾选，漏报会把半句话念进成片。所以这张表**宁滥勿漏**，词表按真实稿子调，且允许人一次性"全部标为正文"批量降级。

`@上屏` 与 `【】` 之外，BGM/音效/剪辑标记走**高置信预选"删"**（不是低置信标黄）——正文里几乎不会以"淡出转场"开头说话，误伤率极低，没必要占用人注意力。
