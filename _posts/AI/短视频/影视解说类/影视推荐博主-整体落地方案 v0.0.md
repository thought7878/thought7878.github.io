# 如何做？

## WorkBuddy

结论先行：这类内容的本质不是“排名”，是**替用户做筛选、帮用户省决策时间**。同质化榜单遍地都是，能活下来的是两种——标准透明的，和敢说缺点的。整套东西四根支柱：**差异化定位、透明评分、结构化条目、固定节奏**。

### 一、先搭生产流水线：机器干粗活，人干信任活

这是我最建议的骨架，核心是分清哪些环节能自动化、哪些必须人来扛：
几个关键判断：

- **前半段（蓝色）全部可脚本化**：抓数据、按公式打分、出候选池，一个 Python 脚本的事，不用人盯。
- **后半段（紫色）必须人干**：定角度、看片、写“这句话值不值得看”——这是信任感的来源，也是别人抄不走的部分。
- **复盘必须回流**：榜单类内容的核心指标是**收藏率**，不是播放量。用户收藏 = 认可你的筛选标准，这是唯一的护城河。

### 二、条目必须卡片化：一张卡片 = 一次决策

榜单里每部剧的展示单元按这个结构做，用户 3 秒决定“看/不看”：
卡片里四个字段各有分工：**双评分**给公信力背书，**一句话定位**回答“适合谁”，**亮点**给看的理由，**排雷+成本**帮用户避坑。缺了后两项，榜单就沦为营销号。

### 三、差异化怎么打

同质化是所有榜单的死穴。破法只有一个：**放弃“总榜”，做“人群 × 场景”的交叉细分**。

- 按人群：职场人下饭档、宝妈带娃档、情侣周末档、学生党寒假档
- 按场景：通勤党（单集 ≤ 25 分钟）、周一打气、深夜emo、倍速刷完
- 按形态：AI 剧前瞻、冷门高分考古、导演/演员专题串讲
- 按数据：成本最低口碑最高（性价比榜）、开画即巅峰后期崩（避雷榜）

选定一个交叉点做成固定栏目，比追热点更能攒住人。

### 四、评分公式要敢公开

公信力不来自“我觉得”，来自“所有人都能复算”。基础版：

> **综合分 = 0.4×豆瓣评分 + 0.3×IMDb/烂番茄 + 0.2×平台热度 + 0.1×新鲜度衰减**

新鲜度衰减 = 上线天数越久分越低（保证“新剧速览”的时效性）。公式写进每期开头，用户信你，黑子也黑不动。

### 五、节奏与指标

- **节奏**：周更固定栏目（如“每周五新剧速览”）+ 热点剧空降加更。固定更新才能养成追更习惯。
- **指标优先级**：收藏率 > 完播率 > 点赞率 > 播放量。榜单内容播放量天然低于娱乐向，别用错尺子。
- **复盘动作**：每月看哪个细分角度收藏最高，下月加权倾斜——这就是流水线底部那个回流箭头。

## Qwen
制作“电影、电视剧、AI剧等新剧排名/榜单”类内容，核心是扮演好 **“专业策展人”** 和 **“观众嘴替”** 的双重角色。要真正解决“剧荒”问题，不能只是简单的片名罗列，而需要提供**决策依据**和**情绪价值**。

以下是系统化的操作指南，分为六个核心模块：

---

### 一、 明确内容定位与受众痛点
“剧荒”的本质不是没有剧，而是**筛选成本太高**或**害怕踩雷**。你的内容需要提供：
1. **降低决策成本**：一句话说明“这部剧为什么值得看”。
2. **精准匹配需求**：按场景、情绪、时长分类，而不是泛泛而谈。
3. **避坑指南**：客观指出缺点（如“节奏慢”、“烂尾风险”），管理观众预期。

---

### 二、 科学的榜单分类维度（拒绝单一评分）
不要只做“Top 10”，要多维度切分，满足不同场景需求：
1. **按情绪/场景价值**（最易引发共鸣）：
   - “周末通宵刷的5部高能悬疑剧”
   - “打工人专属：无需动脑的极致下饭喜剧”
   - “治愈系：看完能睡个好觉的温情短剧”
2. **按时间/时效性**：
   - “本周新剧速览（X月X日-X月X日）”
   - “本月被低估的冷门佳作”
3. **按受众圈层**：
   - “原著党狂喜：高分小说改编剧”
   - “颜控必看：服化道封神的古装/奇幻剧”
4. **按技术/形态创新**（针对AI剧）：
   - “前沿体验：本月值得关注的AI生成短剧/互动剧”

---

### 三、 三种核心形式的具体做法

#### 1. 新剧速览（短平快，主打时效）
- **形式**：图文卡片或1分钟短视频。
- **结构**：剧名 + 海报 + 播出平台/时间 + **一句话核心亮点**（如：“《XX》：张译新剧，开局即高潮，连环反转”） + 推荐指数（⭐️⭐️⭐️⭐️）。
- **关键**：速度要快，通常在剧集开播前1天或开播当天发布。

#### 2. 推荐榜（重深度，主打信任）
- **形式**：中长图文、视频解说或播客。
- **结构**：榜单名称（如“2026年Q3必看的8部科幻剧”） + 排名 + 详细推荐理由（剧情简介无剧透 + 亮点分析 + 适合人群 + 潜在雷点）。
- **关键**：加入“编辑点评”或“真实观众短评”，增加人情味和可信度。

#### 3. 盘点（重主题，主打传播）
- **形式**：深度长文、系列视频。
- **结构**：围绕一个强主题展开。例如：“从《XX》到《XX》，盘点近5年最烧脑的时空循环剧”。
- **关键**：主题要新颖，能唤起观众的集体记忆或好奇心，适合做长尾流量。

---

### 四、 数据来源与评价体系（建立权威性）
榜单不能仅凭个人喜好，需建立透明的评价模型：
1. **专业评分**：豆瓣、IMDb、烂番茄（Rotten Tomatoes）、MyDramaList。
2. **大众热度**：微博热搜、小红书讨论度、抖音播放量、百度指数。
3. **自有评价维度**（建议设计一个“推荐指数”公式）：
   - 剧情创新（30%） + 制作水准（30%） + 演员表现（20%） + 话题讨论度（20%）。
4. **针对“AI剧”的特殊评价标准**：
   - 需明确标注：是“AI题材”还是“AI参与制作（如AI生成画面/剧本/配音）”。
   - 评价维度：技术完成度（画面是否闪烁、连贯性）、叙事新颖性、互动体验（如果是互动剧）。*注：目前AI剧多处于实验性或短剧阶段，需客观指出其技术亮点与叙事短板。*

---

### 五、 内容呈现与视觉包装
1. **统一视觉识别**：设计专属的榜单模板（如“红榜/黑榜”、“神作/可看/避雷”），让观众一眼识别。
2. **信息可视化**：使用雷达图展示剧集的“剧情、演技、视效、节奏、催泪”维度。
3. **提供观看指引**：明确标注播出平台（Netflix、爱奇艺、腾讯视频等）及是否需要会员，甚至提供“在哪里看无删减版”的合法合规提示。

---

### 六、 运营与互动策略（形成闭环）
1. **让观众参与造榜**：在文末/视频结尾发起投票或留言：“你心中的本月最佳是哪部？”“下期想看我盘点什么主题？”，将优质评论置顶，形成社区感。
2. **建立“剧荒急救包”**：在公众号/社群提供关键词回复功能，如用户回复“悬疑”，自动推送历史悬疑剧榜单。
3. **跨平台分发**：
   - 小红书：主打高颜值海报 + 情绪价值文案（“求求了，剧荒的姐妹一定要看这部！”）。
   - 抖音/B站：主打快节奏剪辑 + 犀利吐槽或深度解析。
   - 微信公众号：主打深度盘点 + 完整榜单收藏。

---

### 💡 创新突破口：如何做好“AI剧”这个新兴品类？
由于“AI剧”是较新的概念，做好它能让你在众多影视博主中脱颖而出：
1. **科普与推荐并重**：在推荐AI剧时，简要科普其使用的技术（如Sora、Runway、Midjourney等），满足观众的科技好奇心。
2. **设立“实验性”标签**：明确告知观众，部分AI剧可能在叙事上存在跳跃，但视觉风格独特，降低预期，主打“猎奇”和“前沿体验”。
3. **关注互动微短剧**：目前AI技术结合最多的领域是互动短剧，可以盘点“由观众选择剧情走向的AI互动剧”，强调其游戏化体验。

**总结**：解决“剧荒”的本质是提供**信任感**。当观众发现按照你的榜单去追剧，踩雷率极低且总能找到符合当下心情的作品时，你的榜单就成为了他们不可或缺的“数字观影指南”。
