## 课程描述  
这门课程绝对“狂野”。我为你准备了一场*为期三周的编码代理（Coding Agents）* 冒险之旅，旨在*让所有背景的人——从非技术人员到资深工程师——都能以惊人的速度交付大型软件项目*。  

感觉我们在2026年已经到达了一个拐点：编码代理工作快速、独立且可靠。大多数时候，它们像魔法一样神奇；有时也会让人沮丧——比如它们草率下结论，或产出糟糕的代码。  
·
但大多数时候，它们令人惊叹。而且，正如我们将亲眼所见，偶尔它们的表现简直令人瞠目结舌！  

传奇AI科学家安德烈·卡帕西（Andrej Karpathy）——“氛围编程（Vibe Coding）”一词的发明者——最近发了一条著名的推文。他说，这些编码代理感觉就像我们从外星人那里得到的工具，而且没有附带说明书。  

好吧——这门课程就是那本“说明书”！  

在3周内，我将带你坐一趟过山车。我们首先从Cursor、Copilot、Codex和Antigravity轻松起步，涵盖AGENTS_md和上下文管理的最佳实践。然后节奏加快，我们进入YOLO模式，从零开始构建完整产品。  

第二周来真的了。我们从氛围编程转向专业级别的氛围工程。我们卷起袖子，深入钻研Claude Code，覆盖斜杠命令、检查点、MCP、Skills、插件、Ralph Loops。我们还会了解OpenCode和Amp。到本周末，我们可以在Jira中提交一个问题，然后惊讶地看着我们的编码代理自动接手、构建、测试，并将更改推送到GitHub。
