# 总结
这段内容主要*演示了如何用 Cursor 在“YOLO 模式”下，通过一个简单的指令让 AI 代理自动构建一个个人作品集网站*。

**核心流程如下：**

1. **项目初始化**  
   - 在 Cursor 中新建项目文件夹 `site`。  
   - 创建 `.env` 文件并填入 `OPENROUTER_API_KEY`（或 `OPENAI_API_KEY`）。  
   - 创建 `.gitignore`，将 `.env` 加入忽略列表，防止密钥被提交。

2. **准备资料**  
   - 将 LinkedIn 个人资料保存为 PDF，放入项目目录，作为网站内容来源。

3. **配置 Cursor 的 Agent（YOLO）**  
   - 将 Agent 的 Auto Run 设为“Run Everything in Sandbox”（完全自动运行）。  
   - 模型选择 GPT-5.2 Codex High，以获得更强代码生成能力。

4. **下达指令**  
   - 直接粘贴一段简短指令：  
     > “请用 Next.js 构建一个专业、惊艳、企业感与个性并存的本地网站，使用 LinkedIn.pdf 的内容，包含 About Me、Career Journey、Portfolio 等，完成后告诉我。”  
   - 没有写详细的 AGENTS.md，完全依赖模型自主发挥。

5. **运行与调试**  
   - 按提示进入 `web` 目录运行 `npm run dev`。  
   - 首次打开 `localhost:3000` 出现错误。  
   - 直接把错误信息复制粘贴给 AI，只说“让它工作”，不做解释。  
   - AI 快速修复后，网站成功启动。

6. **结果评价**  
   - 网站视觉效果令人满意，风格确实“企业感 + 个性”。  
   - 功能包括 About Me、Career Journey、Portfolio、邮箱联系、LinkedIn 链接等。  
   - 整体认为是一个很好的网站，但还缺少真正的交互功能，下一步准备添加功能。

**关键点**：整个过程几乎不手动写代码，体现了“YOLO 模式”的高效与风险——虽然第一次出错，但通过简单反馈即可继续，适合快速原型开发。
