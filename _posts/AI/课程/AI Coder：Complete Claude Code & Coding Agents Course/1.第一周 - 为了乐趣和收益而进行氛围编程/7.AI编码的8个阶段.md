In this lecture, you'll explore a powerful framework for understanding AI adoption in coding — the 8 stages of AI, originally described by Steve Yegge.  
中文：在本讲座中，你将探索一个理解AI在编码中应用的有力框架——AI的8个阶段，最初由Steve Yegge提出。

You'll walk through each phase step by step, starting from basic prompt interactions with ChatGPT and AI autocomplete (Stage 1), moving through agentic coding in an IDE like Cursor with manual approval workflows (Stage 2), and progressing into YOLO mode where you trust the AI agent to execute changes autonomously (Stage 3).  
中文：你将逐步走过每个阶段，从**与ChatGPT和AI自动补全的基本提示交互**（`阶段1`）开始，**经过在IDE（如Cursor）中带有手动审批工作流的代理编码**（`阶段2`），再**进入YOLO模式，即你信任AI代理自主执行更改**（`阶段3`）。

You'll learn the conceptual shift at Stage 4, where your attention moves from the code to the agent itself, and then the leap to Stage 5 — working with a CLI-based coding agent like Claude Code, letting diffs scroll by as the agent builds for you.  
中文：你将了解`阶段4`的概念性转变——**你的注意力从代码转移到代理本身**，然后跳到`阶段5`——**使用基于CLI的编码代理（如Claude Code），让差异代码滚动显示，由代理为你构建**。

From there, you'll see how multi-agent systems come into play: spawning multiple autonomous agents working concurrently on your project (Stage 6), scaling to 10+ agents you coordinate yourself (Stage 7), and finally reaching full orchestration — where a master agent manages manager agents and worker agents in a structured, goal-oriented hierarchy (Stage 8).  
中文：从那里开始，你将看到多代理系统如何发挥作用：**生成多个自主代理并发处理你的项目**（`阶段6`），**扩展到10个以上由你自行协调的代理**（`阶段7`），**最终达到完全编排——由一个主代理在结构化的、目标导向的层级中管理管理者代理和工作者代理**（`阶段8`）。

中文：*本讲座将这8个层次直接映射到课程结构中*：**第1周使用Cursor和基于IDE的代理工作流覆盖阶段2-4，第2周在命令行中通过Claude Code深入探讨阶段5，第3周则引入阶段6-8的多代理编排**。
