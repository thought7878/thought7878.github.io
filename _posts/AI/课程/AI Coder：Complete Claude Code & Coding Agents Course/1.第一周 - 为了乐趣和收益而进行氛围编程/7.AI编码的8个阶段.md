
# 总结
这段内容主要围绕 Steve Yegge 提出的 AI 编码八个阶段展开，并说明了课程安排以及 AI 成本问题。

## **AI 编码的八个阶段**（Steve Yegge）  
- **阶段 1**：使用 ChatGPT 和 AI *自动补全辅助编码*，只是偶尔参考。  
- **阶段 2**：IDE 侧边栏有编码代理，每次修改*都需人工批准，逐步检查*。  
- **阶段 3**：进入 “YOLO 模式”，*完全信任代理，接受所有改动，不再逐个确认*。  
- **阶段 4**：代理从侧边栏移到主窗口，注意力从代码转移到代理，*偶尔扫一眼 diff，甚至离开让它自己跑*。  
- **阶段 5**：迁移到命令行终端（如 Claude Code），*diff 自动滚动，基本不再检查，可能离开后再回来*。  
- **阶段 6**：*同时运行多个代理（3-5 个），像一个小团队并发工作*。  
- **阶段 7**：*手动管理 10 个以上代理，协调它们并行推进项目*。  
- **阶段 8**：*由代理编排其他代理，形成层级化团队*（如设计团队、测试团队），实现最高级自动化。

## 课程与阶段对应关系  
- 第 1 周：主要覆盖阶段 2-4，在 IDE 环境中使用代理。  
- 第 2 周：深入阶段 5，重点使用 Claude Code 等 CLI 工具。  
- 第 3 周：引入阶段 6-8，包括多代理和代理编排。  
- 作者认为**企业级高质量软件开发的最佳区间**在阶段 5 和 6 之间，因此*课程会重点聚焦这两阶段，阶段 7-8 只做展示和了解*。

## AI 成本说明  
- 可以零成本完成整个课程，完全使用免费模型和资源。  
- 推荐方案：先试用 Cursor Pro 免费期，第 2-3 周使用 Claude Code 的 20 美元/月套餐，如需更高强度再增加投入。  
- 成本责任在学员自己，需要自行监控各平台费用，讲师会提供透明信息和指引，但不承担费用责任。  
- 解释了 AI 服务收费的合理性：涉及大量计算和电力成本，类比购买高价笔记本电脑，不应惊讶于每月几十美元的支出。  
- 强调学员是成本控制的主导者，遇到问题可随时询问。
