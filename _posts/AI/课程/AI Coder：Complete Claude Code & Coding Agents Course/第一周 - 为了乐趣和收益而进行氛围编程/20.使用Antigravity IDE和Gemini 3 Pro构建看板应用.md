# 总结
这段内容主要演示了*第四个 AI 编码工具 Antigravity 的使用，并对比了前面几个工具的模型差异*。

1. 模型差异回顾  
- Codex 使用了前沿模型 GPT-5.2 Codex（高推理），因此效果最好。  
- Cursor 使用的是内部优化模型 Composer，成本较低，但不如 Codex。  
- GitHub Copilot 使用的是 Claude Haiku 4.5，较小模型，效果也不错但稍弱。

2. 项目重置  
- 回到 Cursor 的 Instant 项目，进入 projects 目录。  
- 将上一轮 Codex 生成的 kanban 文件夹重命名为 `codex_kanban` 存档。  
- 再次 `git clone` 仓库，获得全新的 kanban 文件夹，只含 `agents.md`。

3. 安装与配置 Antigravity  
- 网站 antigravity.google，下载安装对应平台版本。  
- Antigravity 也是 VS Code 的 fork，界面与 Cursor、VS Code 相似。  
- 登录 Google 账号，打开 kanban 项目。  
- 右侧 Agent 聊天显示 Gemini 3 Flash，可切换模型，保留计划模式。  
- 设置中开启自动修复 lint 错误，并将权限设为 “always proceed”（类似 YOLO 模式）。

**4. 配置规则文件**  
- Antigravity 不采用 `agents.md` 标准，而是使用 `.agent/rules/` 目录。  
- 新建 `.agent/rules/strategy.md`，将原 `agents.md` 内容复制进去，激活模式设为 “always on”。  
- 删除根目录的 `agents.md`，避免混淆。

**5. 构建过程与结果**  
- 使用 Gemini 3 Pro high 模型，输入 “Please go ahead” 开始构建。  
- 过程中自动启动浏览器、使用 Playwright 进行测试并录制屏幕，修复发现的错误。  
- 完成后打开浏览器查看：界面清爽美观，拖拽、重命名等功能正常。  
- 但添加卡片功能较简陋，无法添加描述，有待后续改进。

**整体评价**：Antigravity 的自动化测试和界面效果令人印象深刻，添加卡片功能是当前最明显的不足。
