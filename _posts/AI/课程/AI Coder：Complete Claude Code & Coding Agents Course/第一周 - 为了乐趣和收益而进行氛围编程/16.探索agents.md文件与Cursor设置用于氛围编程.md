# 总结
这段内容主要讲解了*在 Cursor 中进行“vibe coding”的准备工作*，包括**快捷键、项目文件说明、如何编写 agents.md 需求文档、Cursor 的自动运行设置**。

## Cursor 快捷键  
- 左侧文件栏切换：Mac 用 Command+B，PC 用 Ctrl+B。  
- 右侧 Agent 聊天栏切换：Mac 用 Command+Option+B，PC 用 Control+Option+B。

## 项目文件与目标  
- 仓库里只有一个文件 `agents.md`，*它是 Agent 默认加载的说明文档*，用 Markdown 编写。  
- **目标**是*构建一个简单的看板（Kanban）项目管理应用 MVP*：单板、五个可重命名列、卡片只有标题和详情、支持拖拽、添加和删除卡片，无搜索/筛选/归档，界面美观，带示例数据。

## 编写 agents.md 的要点  
- *需求要精确、清晰、果断，避免歧义*；可以*适当重复重要点*。  
- **技术细节**：使用 Next.js，放在 `frontend` 子目录，无持久化和登录，用流行库，UI 优雅。  
- 可提供配色方案，也可省略让 AI 自行决定。  
- **策略部分**：制定带成功标准的计划，包括脚手架、单元测试、执行计划、集成测试（Playwright），直到 MVP 完成并测试通过。  
- **编码标准**：使用最新库和惯用方法、保持简单不过度设计、无多余防御编程、README 简洁、禁止 emoji。

## 如何起步  
- 可以直接复制现有 agents.md，也可以从极简版本开始，运行后根据问题迭代修改。  
- 这些规则可以逐步添加个人偏好，后续会学习集中管理。

## Cursor 自动运行设置  
- 通过设置菜单或快捷键（PC Ctrl+Shift+J / Mac Command+Shift+J）进入 Agents 的 Auto Run 部分。  
- 可选择 YOLO 模式（无沙箱，全自动）或沙箱/每次询问，根据个人风险偏好决定。作者因项目低风险而选择 YOLO 模式。
