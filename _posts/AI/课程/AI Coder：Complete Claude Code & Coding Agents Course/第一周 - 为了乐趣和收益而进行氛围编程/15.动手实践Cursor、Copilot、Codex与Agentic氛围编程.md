# 总结
这段内容是对一堂*实操课开场的讲解*，主要包含以下几个部分：

1. **课程定位与心态原则**  
   - 今天是“Yellow Day”，开始*动手使用各种 agentic AI 编码产品*（如 Cursor、Copilot、Codex、Antigravity 等）。  
   - 所有展示的产品都是可选的，不必全部安装，挑一个喜欢的用即可。  
   - 不同人使用不同模型（免费/付费/不同版本），结果会不一样，要接受差异。  
   - *遇到 agent 输出不合理时，保持耐心、给反馈；如果不行就简化问题、缩小范围；再不行可删除重来或跳过该产品*。  
   - 最重要的是享受过程，不要沮丧。

2. **准备工作：安装 Node.js**  
   - 从课程资源中找到 Node.js 官网链接（nodejs.org），根据系统（Mac/Windows）下载安装。  
   - 可以在 Cursor 的终端（View → Terminal）里运行安装命令，安装后用 `node --version` 验证版本（22 以上即可）。  
   - 如果遇到问题，可通过课程问答或邮件求助。

3. **项目切换：从 Instant 到 Kanban**  
   - 先在终端中用 `pwd` 确认当前目录，用 `cd ..` 返回上级项目目录。  
   - 使用 `git clone` 命令克隆课程提供的 GitHub 仓库（`https://github.com/ed-donner/kanban.git`）。  
   - 克隆完成后，在 Cursor 中通过 File → New Window → Open Project 打开 kanban 项目。  
   - 打开后界面左上角会显示 Kanban，表示成功进入新项目，可以开始工作。

**整体目标**：让学员熟悉不同 AI 编码工具，完成环境搭建，并顺利切换到 Kanban 项目，为后续实操做好准备。
