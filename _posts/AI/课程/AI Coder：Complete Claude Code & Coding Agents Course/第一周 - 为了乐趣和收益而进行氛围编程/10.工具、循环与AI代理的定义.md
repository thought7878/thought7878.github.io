## 3.工具
And then trick number 3 is called tools. And of course, this is a really exciting one. It really took off in a massive way last year and a bit the year before as well.

然后*第三招叫做工具*。当然，这是一个*非常令人兴奋的招数*。它在去年以及前年一点点时间里真的大规模流行起来。

Tools is about realizing that when we have LLMs generate tokens—the most likely output—we could use those tokens not just to generate a text response, but also to decide whether or not the LLM would like to carry out some actions that it's been told it could do. So in the prompt, in the input that you send the LLM, you can say, "Hey, I'd like you to answer my question, but by the way, you can also respond with some special tokens to say I would like to search the internet or I would like to use a calculator or I would like to run some Python code and then tell me what to do." And if you respond with that, then I will do that action for you and then I will call you a second time with the results. And that little clever trick, which is called using tools, allows us to use the LLM not just to generate a text output, but actually to decide to do something. We call it running a tool, and then we will run the tool and provide it back with the response. But you always have to stay grounded in the reality that the LLM itself isn't going off and searching the internet or running Python code. An LLM is just a statistical engine that generates tokens, but we are interpreting those tokens. It's generating tokens that say something like "I would like to run a calculator," and we're interpreting that output and we're running the calculator. So it's always our code, it's always software that ends up calling a tool. We're using the LLM just to generate the tokens to say what it wants to do next. And that whole process is called tool calling, and it's really clever.

`工具`的核心是，**当我们让 LLM 生成 token（最可能的输出）时，我们可以用这些 token *不只是生成文本回复*，还*可以决定 LLM 是否想要执行一些它被告知可以执行的操作***。
所以在提示中，在你发送给 LLM 的输入里，你可以说：*“嘿，我希望你回答我的问题，但顺便说一下，你也可以回复一些特殊 token，表示我想`搜索互联网`，或者我想使用计算器，或者我想`运行一些 Python 代码`，然后告诉我该怎么做”。如果你这样回复，那么我就会替你执行那个操作，然后我会带着结果第二次调用你*。
***而这个聪明的小技巧，也就是所谓的“使用工具”，让我们使用 LLM 不只是生成文本输出，而是实际上决定去做某件事***。我们称之为***运行一个工具***，然后我们会**运行这个工具并把响应返回给它**。

但你必须始终立足于这样***一个现实：*** ***LLM 本身并不会自己去搜索互联网或运行 Python 代码*。LLM 只是一个生成 token 的统计引擎，但*我们在解读这些 token***。**它生成的 token 在说类似于“我想运行计算器”，而我们解读这个输出，然后运行计算器**。所以***始终是我们的代码、始终是软件最终去调用工具。我们只是使用 LLM 来生成 token，以说明它接下来想做什么***。这整个过程就叫做`工具调用`，它真的很巧妙。

All right, I just want to make this super real for you—just to be very clear, here is something hopefully familiar to you. This is ChatGPT, and I'm going to paste in a question I have for it. Okay, before the question I want to prefix it to use Python code to respond to the next question: just reply "Python:" and then a Python expression. And then my question: what is the square root of pi? A question which perhaps isn't going to be very easy for a language model to respond to, but I'm telling it that it can do something special. It can reply this way if it wants to just execute Python code. So I'm going to run that and we'll see how it responds. And this is how it responds, and you can see that it's done something reasonably advanced because it's doing it all in one, including imports, which I assume will work. But it's actually decided, instead of responding with the square root of pi, it's responding with this Python line of code right here—quite a clever Python line of code. And so you can see that basically it's using a tool. We've equipped ChatGPT with this tool that we've just used language for, and when we've asked it this question, it hasn't given us the answer. It hasn't just told us the square root of pi, but rather it's said that it wants to execute some Python code. And this is a super clear example of what it means to have an LLM use a tool. It's just about giving it a clever input and then interpreting the output. That is what tool calling is all about.

*例子*，我想让这一点对你来说非常真实——为了说得非常清楚，这里有一个希望你熟悉的东西。这是 ChatGPT，我要粘贴一个我想问它的问题。好，在问题之前，我想给它加一个前缀，让它用 Python 代码回答下一个问题：只需回复“Python:”，然后是一个 Python 表达式。然后我的问题是：π 的平方根是多少？这个问题对于语言模型来说可能不太容易直接回答，但我告诉它可以做一些特别的事。如果它想直接执行 Python 代码，它就可以这样回复。所以我要运行它，我们看看它如何响应。这就是它的响应，你可以看到它做了一些相当高级的事情，因为它一次性完成了所有内容，包括导入，我猜这些能正常工作。但它实际上决定，不是回答 π 的平方根，而是用这里这行 Python 代码来回复——相当聪明的一行 Python 代码。所以*你可以看到，基本上它正在使用一个工具*。**我们为 ChatGPT 配备了这个我们用语言描述的工具**，当我们问它这个问题时，它没有给我们答案。它没有直接告诉我们 π 的平方根，而是**表示它想执行一些 Python 代码**。这是一个超级清晰的例子，说明让 LLM 使用工具意味着什么。***这不过是给它一个巧妙的输入，然后解读输出。这就是工具调用的全部意义***。

## 4.循环（Loop）
And the fourth trick is something that's so simple it's super elegant. It's basically saying, what could be better than calling an LLM with an input and getting some output? Or, what could be better is calling it multiple times. In fact, in a loop, we can call an LLM, and then when it's produced its output, we can ask it if it's finished yet. And if not, we just call it again and then again and then again, in a loop, repeating until a goal is met. And that simple idea of calling an LLM multiple times is something that turns out to allow us to achieve much bigger goals than just calling an LLM once with an input and getting an output. And so that fourth trick of the loop is something which allowed us to achieve much bigger things.

第四招非常简单，非常优雅。它基本上是在说：有什么能比调用一次 LLM、输入然后得到输出更好呢？*更好的是多次调用它*。事实上，在一个循环中，我们可以调用 LLM，当它生成输出后，我们可以问它是否已经完成。如果没有，我们就再次调用它，然后再一次、再一次，*在一个循环中重复，直到目标达成*。而 **“多次调用 LLM”这个简单想法**，结果证明**能让我们实现比只调用一次 LLM 大得多的目标**。所以第四招——`循环`，**是让我们实现更大成就的原因**。

- Step 2: Test to see if goal is met  
步骤2：测试目标是否达成
- Step 3: If not, go to Step 1  
步骤3：如果未达成，回到步骤1

So those are four tricks. There are lots of other tricks, but these are the big four tricks that allow us to get from the sort of beginnings—from the ChatGPT of 2022—to some of the high-performance products today, like Cursor Agent and Claude Code.

所以***这就是四个招数。还有很多其他招数，但这是四个主要的招数，让我们从 2022 年的 ChatGPT 那样的早期阶段，走到今天一些高性能产品，比如 Cursor Agent 和 Claude Code***。

## AI agent
Okay, now it's time for me to define an AI agent for you. So there have been a lot of different definitions of AI agents. And in fact, there was a meme a while back that an AI agent could be whatever you wanted it to be, because it was so vague. But because everyone meant something a bit different, there have been a few different definitions that people have really stood behind over the years.

好，现在轮到我为你定义 AI agent 了。关于 AI agent 有很多不同的定义。事实上，之前有个梗说，AI agent 可以是你想要的任何东西，因为它太模糊了。但因为每个人所指的都有些不同，多年来人们真正支持的定义有好几种。

And one of the earliest ones came from OpenAI and others that described it as AI systems that can do work for you independently. This is the idea behind products like GPT Agent, which used to be called Operator. And this was something where you can prompt it and it will, like, open up a browser and you can watch it while it goes off and searches the web. It looks for restaurants that have availability this evening for the particular type of food you like, with reservations for four, and it will make the reservation while you watch. And you have that sense that there is something there that's working autonomously. And that is the sense of having an AI agent that is doing work.

其中最早的一个来自 OpenAI 和其他公司，把它描述为能够独立为你完成工作的 AI 系统。这就是像 GPT Agent（以前叫 Operator）这类产品背后的理念。在这种产品里，你可以给它提示，它会打开浏览器，你可以看着它去搜索网页。它会寻找今晚有位的餐厅，符合你喜欢的特定食物类型，并预订四人位，然后它会在你观看时完成预订。你会有一种感觉：那里有某个东西在自主地工作。这就是拥有一个正在做事的 AI agent 的感觉。

Some other people use a similar definition: that it's something that can act as well as generate tokens. It is an LLM that can act, which, you know, it's hard to be super crisp about what that means, but you kind of know it when you see it. And that was the first of the definitions of an AI agent. And then the next one came, I guess early 2025, and I think it was Hugging Face—first of all, the New York AI startup—that described it as AI systems where an LLM controls the workflow. So an LLM, as it's generating output tokens, those tokens describe what should happen next and orchestrate future LLM calls. That became the definition, and Anthropic kind of doubled down on that with a seminal blog post called "Building Effective Agents" that had a similar definition. And that for a long time was the prevailing definition of an AI agent. But more recently, the definition that's really taken hold, that's become the definition that I think Simon Willison, who I mentioned before, was perhaps the first to really plant the flag and say this is going to be the definition, came in late 2025.

另一些人使用类似的定义：它是既能生成 token 又能行动的东西。它是一个能行动的 LLM，你知道，很难非常精确地说明这是什么意思，但你看到时就会知道。这是 AI agent 的第一个定义。然后下一个定义出现了，我猜是 2025 年初，我想首先是 Hugging Face——那家纽约 AI 初创公司——把它描述为“LLM 控制工作流的 AI 系统”。也就是说，LLM 在生成输出 token 时，那些 token 描述了接下来应该发生什么，并编排未来的 LLM 调用。这成了定义，而 Anthropic 通过一篇具有开创性的博客文章《Building Effective Agents》进一步强化了这个定义，那篇文章也有类似的定义。在很长一段时间里，这就是 AI agent 的主流定义。但更近一些，真正占据主导的定义，也就是我认为西蒙·威利森（我之前提到过）也许是第一个真正站出来宣称这将成为最终定义的人，出现在 2025 年底。

And it is that an agent is where there is an LLM that runs tools in a loop to achieve a goal. It runs tools in a loop to achieve a goal. So it ties back to a couple of those tricks that I just mentioned—tools and loop. So it's something that, again, runs tools in a loop to achieve a goal. And I'm hoping that already clicks for you. But if not, remember what we did yesterday with the Cursor agent when we gave it a goal. We said, "I want a first-person shooter in a web page," and off it went. We'd given it a goal; it was obviously in a loop because we saw stuff happening one after another. We saw files being created.

这个定义是：agent 就是一个 LLM 在循环中运行工具以实现目标。它在循环中运行工具以实现目标。所以它又回到了我刚才提到的几个招数——工具和循环。也就是说，它再次是在循环中运行工具以实现目标。我希望这已经让你豁然开朗。但如果没有，请记住我们昨天用 Cursor agent 做过的实验，当时我们给它一个目标。我们说：“我想要一个网页版第一人称射击游戏。”然后它就开始了。我们给了它一个目标；它显然处于一个循环中，因为我们看到事情一件接一件地发生。我们看到文件被创建。

It was an LLM being repeatedly called again and again, and it had tools. It had tools to write files to disk, it had tools to run code, it had tools to generate code. So it had these various tools, and it was using those tools, and you could see it happening, and so that gave you a first-hand experience of an AI agent. It was running tools in a loop, and we gave it a goal and it achieved it.

它是一个被反复调用的 LLM，一次又一次，而且它拥有工具。它有把文件写入磁盘的工具，有运行代码的工具，有生成代码的工具。所以它有这些各种各样的工具，并且它正在使用那些工具，你可以看到这一切正在发生，所以这给了你一个关于 AI agent 的第一手体验。它在循环中运行工具，我们给了它一个目标，它实现了目标。

So that is the current winning definition of an AI agent.

所以这就是当前胜出的 AI agent 定义。
