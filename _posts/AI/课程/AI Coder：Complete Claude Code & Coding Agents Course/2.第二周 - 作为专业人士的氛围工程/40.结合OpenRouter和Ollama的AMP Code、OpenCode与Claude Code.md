# 总结
这段内容主要*介绍了另外两个工具*——`Amp Code` 以及如何将 `Claude Code` 连接到其他模型提供商（OpenRouter 和本地 Ollama）。要点如下：

## Amp Code 简介  
   - *与 OpenCode 类似的开源 agentic 编码工具*，不隶属于任何模型提供商，可连接多个后端。  
   - 提供终端版以及 VS Code / Cursor / Windsurf 扩展。  
   - 特色是 **Amp Free 计划**：*每天通过观看广告获得约 10 美元的模型使用额度*（并非直接免费，而是广告换额度）。

## Amp 使用体验  
   - 安装后运行 `amp` 启动，首次需登录（支持邮箱或 Google 账号）。  
   - 界面顶部展示广告，作为免费额度的来源。  
   - **不提供手动选择模型**，由 Amp 根据任务自动选择最优模型，用户只需信任其调度。  
   - 可用 `Ctrl+S` 切换模式：**Smart**（标准）、**Deep**（深度思考，较慢）、**Rush**（快速）。  
   - 示例：在 Deep 模式下让 Amp 对整个项目做代码审查，成功生成 `code-review.md`，并发现硬编码凭据等真实问题。  
   - 账户页面显示每日剩余额度（如 $9.58/$10），可购买额外额度或连接 GitHub。

## 将 Claude Code 连接到 OpenRouter  
   - 通过设置环境变量（`ANTHROPIC_BASE_URL` 指向 `openrouter.ai/api`，`ANTHROPIC_API_KEY` 替换为 OpenRouter 密钥，并将默认模型全部设为 Kimi K2）来“欺骗” Claude Code 使用 OpenRouter。  
   - 这种方法并非 Anthropic 官方推荐，配置和体验都较“凑合”（janky）。  
   - 启动命令：`claude --model moonshotai/kimi-k2`（模型名取自 OpenRouter）。  
   - 成功运行简单任务（总结项目用途），OpenRouter 活动页确认调用的是 Kimi K2。  
   - 但让 Kimi K2 做复杂代码审查时效果不佳，说明开源模型与前沿闭源模型仍有差距，需多实验。

## 使用本地 Ollama 运行模型  
   - 通过环境变量将默认模型设为 GPT-OSS，并将 API 地址指向本地 `localhost:11434`（Ollama 默认端口）。  
   - 启动 `claude --model GPT-OSS` 后，让模型总结项目，成功返回结果，且观察到 GPU 满载，证明确实在本地运行。  
   - 本地运行需要强大的硬件（至少 64GB 显存/统一内存），否则速度很慢；普通用户建议用 OpenRouter 或 Amp/OpenCode。

## 总结与建议  
   - 介绍了 *Claude Code、OpenCode、Amp Code 三种工具*，并*演示了 Claude Code 搭配 OpenRouter 和 Ollama*。  
   - 作者个人仍最偏好 Claude Code（针对 Claude 模型优化最佳），但强调*其他工具在免费或灵活性上有优势*。  
   - 提醒关闭终端后环境变量会重置，下次启动即恢复默认 Claude Code。  
   - 最后提到学习进度：已完成课程 40%，下一步将深入掌握 Claude Code 高级用法。
