# 总结
这段内容主要围绕 **Claude Code 的常用命令、快捷键、配置与文件引用技巧** 展开，是 Week 2 Day 2 的深入学习。要点如下：

## 课程回顾与定位  
   - 简要回顾了编码代理工具的格局：**IDE 插件**（Cursor、Windsurf、GitHub Copilot、Codex 等）和 **CLI 工具**（Claude Code、Cursor、Codex CLI、Gemini CLI、Antigravity 等）。  
   - 作者重申自己最喜欢 Claude Code，但其他工具（OpenCode、Amp 等）也可跟随学习，大部分概念通用。

## 常用命令介绍  
   - `/help`：查看命令和快捷键摘要。  
   - `/init`：初始化项目，自动生成 `Claude.md`（也可手动编写）。  
   - `/model`：查看或切换当前使用的模型。  
   - `/status`：查看版本、设置和用量概况。  
   - `/context`：显示当前上下文记忆（作者高频使用）。  
   - `/compact`：压缩上下文，重置会话；可附带总结指令，建议主动执行而非等系统自动触发。  
   - `/clear`：彻底清空对话历史（相当于重启 Claude），作者喜欢用这种方式保持环境干净。  
   - `/config`、`/usage`、`/stats`：分别展示配置、用量和统计图表（stats 可显示 token 消耗和模型使用情况）。  
   - `/permissions`：管理权限规则，也可直接编辑 `.claude` 目录下的 JSON 文件。

## 快捷键与模式  
   - **Shift+Tab**：切换“自动接受编辑”模式；再按一次可开启 Plan 模式（但作者认为 Opus 已能自行判断是否需要计划，故较少强制使用）。  
   - **Ctrl+O**：切换详细输出模式，显示更多底层细节。  
   - **Ctrl+Shift+\`**：在 VS Code 中打开全新终端（避免残留环境变量）。

## 配置文件与权限管理  
   - `.claude` 目录中有一个 JSON 文件，记录了所有已允许的权限（例如允许执行某些命令或编辑文件）。  
   - 用户可直接编辑该文件来添加或移除权限，也可通过 `/permissions` 命令操作。

## @ 符号引用文件/目录  
   - *在提示词或 `Claude.md` 中*使用 `@路径` **可引入文件内容到上下文**。  
	   - 例如 `@docs/plan.md` 会把该文件内容插入；`@目录` 只引入目录列表而非全部文件。  
   - 实用技巧：用 `@agents.md` 让 `Claude.md` 直接引用 `agents.md`，实现多工具共享同一份指令文件，避免重复维护。

## 作者工作习惯  
   - 偏好**保持 `.md` 文件更新，定期 `/clear` 或重启获得干净上下文**。  
   - 提醒*使用 @ 引用长文件会快速消耗上下文，需谨慎*。  
   - 后续会深入学习 checkpointing 等高级功能。
