# 总结
这段内容主要介绍了 **OpenCode** 这款开源 AI 编程工具，并与 Claude Code 进行了对比。要点如下：

1. **OpenCode 简介**  
   - 开源的 Claude Code 替代品，可免费使用内置模型，也可连接任意提供商的模型（如 ChatGPT、Gemini 等）。  
   - 支持通过 npm 安装，Mac 和 Windows 均有对应安装方式。

2. **基本使用体验**  
   - 在 VS Code 终端中运行 `opencode` 启动。  
   - 会自动检测已有的 OpenAI 登录信息，默认使用 GPT-5.2 模型。  
   - 可用 Tab 切换 Plan（规划）和 Build（执行）模式，用 Ctrl+T 调整推理强度（低/中/高/极高）。  
   - 通过 `/models` 切换模型，`/connect` 连接其他服务商。

3. **免费开源模型测试**  
   - 选择了 GLM-4.7（来自 Z.ai）进行代码审查测试。  
   - 在 Plan 模式下让它分析项目并生成审查文档，再切换到 Build 模式实际写入文件。  
   - 生成的审查报告内容详细、质量不错，但作者认为与 Claude Opus 4.5 等前沿模型相比，独立完成复杂重构的可靠性仍有差距。

4. **免费使用的限制**  
   - 目前没有明确配额，但过度使用可能会限速或报错，政策也可能变化。

5. **连接其他模型与本地运行**  
   - 可连接 OpenAI、Anthropic、GitHub Copilot、Google、OpenRouter、Azure、Bedrock 等。  
   - 也可通过 Ollama 本地运行模型，但需要至少 64GB 显存或统一内存，门槛较高。

6. **总结与建议**  
   - OpenCode 灵活性强，支持多模型切换，适合免费或低成本使用。  
   - 作者个人更偏好 Claude Code，认为其针对 Claude 模型的优化体验最佳，但 OpenCode 完全可以作为跟随学习的替代工具。
