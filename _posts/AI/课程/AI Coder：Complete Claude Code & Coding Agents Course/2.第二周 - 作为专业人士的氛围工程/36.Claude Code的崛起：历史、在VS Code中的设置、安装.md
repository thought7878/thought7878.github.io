# 总结
这段内容主要*介绍 Claude Code 的起源、发展、安装方式、与 VS Code 的集成*，并说明了订阅费用和使用建议。

**1. Claude Code 的起源与发展**  
- 始于 2024 年底，Anthropic 工程师 Boris Cherny 的副项目 Claude CLI，用于驱动 Claude 进行代理式编码。  
- 2025 年 2 月向多数人开放，4 月正式发布，是首个真正流行起来的 CLI 编码工具。  
- 2025 年 9 月发布 V2，带来成熟的生态系统：检查点、子代理、技能、后台任务，以及用于在 Claude Code 生态内编程的 SDK（不同于 OpenAI Agents SDK）。  
- 模型演进：从 Claude Sonnet 4.5（当时顶尖模型之一）到 2025 年 11 月发布 Opus 4.5，被视为代理式编码的拐点，*可靠性大幅提升，人们开始信任代理自动完成大量代码而无需频繁检查 diff*。  
- 同期 Anthropic 的 Claude Code 年化收入突破 10 亿美元，之后推出 Cowork（将类似理念扩展到编码之外）以及开源的 OpenClaw，并投资 Labs 探索更前沿用法。  
- 提醒不要过度追逐短期热点，Claude Code 已被证明会长期存在。MCP（模型上下文协议）也是其生态重要部分，月下载量达 1 亿次，课程会覆盖。

**2. 安装与订阅**  
- Claude 平台提供免费聊天、Pro（20 美元/月，支持网页和终端使用 Claude Code）、Max（100/200 美元/月）。  
- 讲师使用 200 美元/月套餐，认为物超所值，但强调这是个人选择，也可以完全免费使用（后面会讲免费/廉价模型配置）。  
- 安装步骤：访问 claude.ai 注册账号；然后到 code.claude.com 获取对应系统的安装命令；在 VS Code 终端中粘贴执行即可完成安装。  
- 同时建议安装 VS Code 的 Claude Code 扩展（在扩展市场搜索，来自 Anthropic 官方验证，下载量近 400 万）。

**3. VS Code 中两种使用方式**  
- **侧边栏方式**：点击顶部 Claude 图标，在侧边栏中使用扩展，更*集成于 VS Code*，适合新手，但*功能受限*，属于较“打包”的版本。  
- **终端方式**：*在 VS Code 集成终端中*直接运行 `claude` 命令，*使用完整功能的 CLI 版本*，同时仍可利用文件浏览器和 VS Code 其他工具，是本周*推荐的方式*。  
- 本周目标是成为“vibe engineer”，因此选择终端方式以获得全部专业功能。
