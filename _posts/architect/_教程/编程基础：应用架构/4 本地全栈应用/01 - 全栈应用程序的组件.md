# 原文
As applications grow in complexity, organizing their structure becomes crucial. In this chapter, we'll explore a full stack application where the front end and back end are distinct components. This separation is vital for building scalable and maintainable applications. 

**随着应用程序复杂性的增长，组织它们的结构变得至关重要**。在本章中，我们将探索一个完整的堆栈应用程序，其中前端和后端是不同的组件。这种分离对于构建可伸缩和可维护的应用程序至关重要。

The front end, or client side, handles the user interface and what the user interacts with. Meanwhile, the backend or server side processes inputs and performs necessary calculations to send results back to the client. 

`前端`或客户端处理用户界面以及用户与之交互的内容。同时，`后端`或服务器端处理输入并执行必要的计算，将结果发送回客户端。

Communication between the front end and back end typically happens over Http, though other protocols can be used. The front end sends requests to the backend using API endpoints. These are specific Url's designed to handle various actions such as retrieving data, saving new information, or updating existing records. The server operates on a specific port, a numerical identifier that distinguishes different services running on the same machine. For example, a server might listen on port 3000 for incoming requests while the front end communicates with it through this port. The back end processes these requests, interacting with data storage if needed, and responds with the requested data or confirmation of the action. This exchange allows the user to interact seamlessly with the application, with the front end updating dynamically based on the responses it receives from the server. 

前端和后端之间的通信通常通过Http进行，尽管可以使用其他协议。前端使用API端点向后端发送请求。这些是特定的Url，用于处理各种操作，如检索数据、保存新信息或更新现有记录。服务器在特定端口上操作，该端口是区分在同一计算机上运行的不同服务的数字标识符。例如，服务器可能会在端口3000上侦听传入请求，而前端则通过此端口与之通信。后端处理这些请求，如果需要与数据存储交互，并以请求的数据或操作确认进行响应。这种交换允许用户与应用程序无缝交互，前端根据从服务器收到的响应动态更新。

We'll be exploring a to do list application. The front end consists of HTML for the structure, CSS for the styling, and a bit of JavaScript for basic interactions, the back end powered by Node JS and Express, has API endpoints for managing specific tasks such as creating, reading, updating, and leading items. Node JS is a job JavaScript runtime that enables server side JavaScript execution, while Express is a framework that sits on top of Node JS and simplifies handling Http requests and responses. Currently, tasks are stored in memory on the server using an array data structure. This means the task list exists only while the server is running and is lost when the server restarts. Later. In this chapter, we'll enhance this component by integrating a database, allowing for persistent storage and retrieval even after the server restarts, Every component in a full stack application plays a crucial role in ensuring overall functionality, maintainability, and scalability of the application.

我们将探索待办清单应用程序。前端由HTML结构组成，CSS用于样式设置，以及一些用于基本交互的JavaScript，后端由Node JS和Express提供支持，具有API端点用于管理特定任务，如创建、读取、更新和引导项目。Node JS是一个JavaScript运行时，支持服务器端JavaScript执行，而Express是一个框架，它位于Node JS之上，简化了Http请求和响应的处理。目前，任务使用数组数据结构存储在服务器的内存中。这意味着任务列表仅在服务器运行时存在，并在服务器重新启动时丢失。稍后。在本章中，我们将通过集成数据库来增强该组件，即使在服务器重新启动后也允许持久性存储和检索，全栈应用程序中的每个组件在确保应用程序的整体功能、可维护性和可伸缩性方面起着至关重要的作用。
