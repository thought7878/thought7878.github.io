云计算对企业的主要好处是什么？  
答：云计算*使企业能够快速响应不断变化的需求，轻松扩展应用程序，降低成本，同时专注于创新而不是基础设施*。  
  
云计算与传统的本地服务器基础设施有何不同？  
答：云计算提供了通过互联网按需访问计算资源的方式，而不是传统的要求企业拥有和维护物理硬件的本地服务器，这导致了可扩展性方面的挑战和运营成本的增加。  
  
“基础设施” 一词在云计算背景下指什么？  
答：在云计算中，`基础设施`是指*支持应用程序操作的基础物理和虚拟资源*，包括**计算、存储、数据库、网络和安全服务**。  
  
云提供商提供的基础设施服务的品类有哪些？  
答：云服务提供商提供基础设施服务，例如用于处理能力的计算服务、用于数据管理的存储和数据库服务、用于数据通信的网络服务，以及用于数据保护和用户访问管理的安全和身份服务。  
  
基于云的应用程序中的前端和后端组件是什么？  
答：基于云的应用程序将具有前端和后端组件，类似于全栈应用程序，并由专门的团队在云端管理和优化这些组件，以满足特定的软件需求。

# 原文
Cloud computing has revolutionized how we design, deploy, and manage applications. Instead of relying on on the premise infrastructure, modern cloud applications are built to be scalable, resistant, and flexible, enabling businesses to respond quickly to changing demands. 

云计算已经彻底改变了我们设计、部署和管理应用程序的方式。现代云应用不再依赖传统基础设施，而是以可扩展、高韧性与灵活性为核心进行构建，使企业能够快速响应不断变化的业务需求。

Traditionally, companies owned and maintained the machines that hosted their software applications, commonly referred to as on-premise servers. This required businesses to invest and maintain in the physical hardware, leading to scalability challenges and increased operational costs. Cloud computing changes this model by providing on demand access to computing resources over the Internet, allowing businesses to scale applications effortlessly, reduce costs, and focus on innovation rather than infrastructure. 

传统上，公司拥有和维护托管其软件应用程序的机器，通常称为*本地服务器*。这要求企业投资和维护物理硬件，导致可扩展性挑战和运营成本增加。*云计算改变了这种模式，通过互联网提供对计算资源的按需访问*，使企业*能够轻松扩展应用程序，降低成本，并专注于创新而不是基础设施*。

Before exploring cloud application components, it's important to understand infrastructure. Infrastructure refers to the foundational physical and virtual resources that support the operation of an application. Traditionally, this included physical servers, storage, and networking hardware. But in the cloud, this infrastructure is virtualized. Cloud providers like AWS Azure and Google Cloud offer scalable, flexible, and cost effective resources through services, allowing businesses to access various infrastructure resources without owning the underlying hardware. These infrastructure services can be grouped into categories. For example, there are compute services that provide the processing power needed to run applications and perform tasks. They offer virtual machines that act like flexible, adjustable computers and serverless functions that let you run code without managing the server that's running it. 

在探讨云应用组件之前，理解基础设施至关重要。`基础设施`是指*支撑应用程序运行的基础性物理和虚拟资源*。传统上，这包括*物理服务器、存储设备和网络硬件*。但*在云环境中，这一基础设施已实现虚拟化*。AWS、Azure和Google Cloud等云服务提供商*通过各类服务提供可扩展、灵活且经济高效的资源，使企业无需自建底层硬件即可按需获取多种基础设施资源*。这些基础设施服务可以被归类。例如，有一些`计算服务`能够*提供运行应用程序和执行任务所需的算力*。他们提供虚拟机，*这些虚拟机就像灵活可调的计算机*；同时还*提供`无服务器函数`，让您无需管理运行代码的服务器即可执行代码*。

Storage and database services handle diverse data needs, from simple file storage to complex databases, and networking services ensure smooth and secure data communication. Security and identity services also safeguard data and manage user access. 

`存储`和`数据库`服务*处理各种数据需求，从简单的文件存储到复杂的数据库*。`网络服务`确保顺畅、安全的数据通信。`安全和身份服务`还可以保护数据并管理用户访问。

Much like in full stack applications. A cloud based application will have front end and backend components. However, with the dedicated infrastructure in the cloud, you might have entire teams dedicated to managing and optimizing sets of these components to address a given software need.

与全栈应用非常相似。基于云的应用程序将包含前端和后端组件。然而，借助云中的专用基础设施，您可能会组建专门的团队，负责管理和优化这些组件的组合，以满足特定的软件需求。
