# 原文

Visibility into user behavior and system performance is crucial for maintaining a reliable and user friendly experience. These are typically separated into two main categories, analytics and monitoring. 

**对用户行为和系统性能的`可观测性` 对于持续提供可靠且易用的用户体验至关重要。这些通常被划分为两大类：`分析`与`监控`**。

Analytics focus on capturing and analyzing data related to user interactions within your application. This includes understanding what users do, how they navigate through your app, and what content or features they engage with most. By leveraging analytics, you can make informed decisions to improve user experience and optimize the application. In our recipe application, we might want to add analytics on user engagement, such as how much time they spend on the site, page views per session, and bounce rates. This can help you understand how engaged your users are with your content, which can guide future product decisions. 

`分析`功能**专注于采集并分析与用户在您的应用中交互相关的数据**。这包括**了解用户的行为、他们在您的应用中的导航路径、他们最常互动的内容或功能。通过运用数据分析，您可以做出明智的决策，从而提升用户体验并优化应用性能**。在我们的食谱应用中，我们可能希望加入用户行为分析功能，例如用户在网站上的停留时长、每会话的页面浏览量以及跳出率等指标。*这有助于您了解用户对内容的参与度，从而为未来的产品决策提供参考*。

Monitoring focuses more on the health and performance of your application. In the case of our recipe app, we would want to monitor the performance of our API endpoints. The key metrics to monitor are response times, error rates, and request volume. We want to make sure that the response times for a given API call are low and error rates are low to avoid negatively impacting the user experience. In the case of an increased error count, logs can be used to troubleshoot and debug. We also want to keep an eye on request volume or how many requests are being received by our service so we can be ready to scale our resources as needed. This monitoring is typically done through alerting where automated alarms go off. 

`监控`更**侧重于应用程序的健康状况和性能表现**。就我们的食谱应用而言，我们希望对API端点的性能进行监控。需要重点**监控的关键指标**包括*响应时间、错误率和请求数量*。我们希望*确保特定API调用的响应时间短、错误率低，以避免对用户体验造成负面影响*。*在错误计数增加的情况下，可以通过日志进行故障排查与调试*。我们还希望*实时监控请求量，即我们的服务正在接收的请求数量，以便在必要时及时扩展资源。此类监控通常通过告警机制实现，即在触发特定条件时自动发出报警*。

If a given metric has an abnormal value for a set period of time. This allows you to address the issue before it impacts real users. By adding these components to your application, you can achieve greater visibility into your systems and continuously optimize the user experience.

如果某项指标在一段时间内出现异常值。这使您能够在问题影响到真实用户之前予以解决。**通过将这些组件集成到您的应用中，您可以更全面地洞察系统运行状况，并持续优化用户体验**。
