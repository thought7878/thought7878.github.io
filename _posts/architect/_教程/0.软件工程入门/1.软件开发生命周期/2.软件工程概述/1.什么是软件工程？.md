- **`软件工程`的定义是什么？**  
答：软件工程是*将科学原理（思想、方法、工具）应用于软件的设计和创建，使用系统的方法来收集和分析业务需求，以便设计、构建和测试软件应用程序以满足这些需求*。  
  
- **软件工程是如何发展的？**  
答：软件工程从1950年代末的一个未定义的学科发展到1960年代的一个现代化的工程领域，随着新技术的发展以及软件开发方法变得更加科学和正式。  
  
- **`软件危机`及其影响是什么？**  
答：软件危机始于20世纪60年代中期，一直持续到1980年代中期，其标志是软件开发效率低下，导致项目经常超出预算，落后于计划，并产生无法管理的，有漏洞的代码。 这导致需要频繁重构或完全重新设计系统，而小型系统的现有解决方案无法扩展到大型复杂项目。

- **`软件工程师`和`软件开发人员`有什么区别？**

- **`软件开发生命周期 (SDLC)` 的目的是什么？**  
答：软件开发生命周期 (SDLC) 的目的是*确定开发高质量软件所需的步骤。 它指导开发过程，并在软件工程和开发的背景下进一步讨论*。

# 原文

Welcome to What is software engineering? After watching this video, you will be able to define software engineering, list the responsibilities of a software engineer, and compare and contrast software developers and software engineers. 
欢迎来到什么是软件工程？**观看此视频后，您将能够定义软件工程，列出软件工程师的职责，并比较软件开发人员和软件工程师**。

Software engineering is the application of scientific principles to the design and creation of software. The field uses a systematic approach to collect and analyze business requirements in order to design, build, and test software applications to satisfy those business requirements. 
`软件工程`是**将科学原理应用于软件的设计和创建**。该领域**使用系统化的方法来收集和分析业务需求，以便设计、构建和测试软件应用程序以满足这些业务需求**。

When computing began in the late 1950s, software engineering was a relatively undefined discipline, but over time it transformed into a modernized engineering field. The software engineering field became a discipline in the 1960s and evolved as new technology were developed and the approach to software development became more scientific. Trends in software engineering transformed from ad hoc programming towards more formal and standardized methods. 
*当计算机在1950年代后期兴起时，软件工程还是一门相对不确定的学科，但随着时间的推移，它转变为一个现代化的工程领域*。软件工程领域在1960年代成为一门学科，随着新技术的发展以及软件开发方法的科学化而不断发展。软件工程的趋势从临时编程转变为更加正式和标准化的方法。

Initially, the creation of software lacked a formal development process. As the world widely adopted computers, software became increasingly integral to more aspects of life. The inefficiencies and the software development process made it difficult to meet the rapidly increasing demand for computing resources and complex software. This led to what is known as the software crisis, which began in the mid 1960s and lasted until the mid 1980s. During this period, software development often ran over budget, behind schedule, and consisted of unmanageable, buggy code. By the time older software solutions came to fruition, newer, better, and faster technologies had already been developed, causing software engineers to have to refactor their code or completely redesign their system. Often, software development solutions that worked for small software systems did not scale to large, complex projects. Now, some of these issues still exist today, although to a much lesser extent due to the consistent application of engineering principles to the software development process, computing resources have become more widely available, and standardized. 
**最初，软件开发缺乏规范的开发流程**。随着计算机在全球范围内的普及，软件在人们生活的方方面面中日益不可或缺。*效率低下以及软件开发流程，使得难以满足日益增长的计算资源需求和复杂的软件开发要求*。这导致了所谓的“`软件危机`”，这场危机始于20世纪60年代中期，持续至80年代中期。**在此期间，软件开发往往超出预算、进度滞后，且代码难以维护、漏洞频出**。等到那些老旧的软件方案终于落地时，更新、更优、更快的技术早已问世，迫使软件工程师不得不重构代码或彻底重设计系统。通常，那些在小型软件系统中行之有效的开发方案难以扩展至大型、复杂的项目。如今，其中一些问题依然存在，尽管程度已大为缓解，*这得益于工程化方法在软件开发过程中的持续应用、计算资源的日益普及与标准化*。

Methodologies for software development allow for large, complex solutions that scale the solution to the software crisis involved, transforming unorganized coding efforts into an established engineering discipline. 
`软件开发方法学`能够支撑大型、复杂的解决方案，有效应对软件危机，*将无序的编码实践转化为一门成熟的工程学科*。

The mid 1980s also saw a rise in the growth of computer aided software engineering or case, which also helped to relieve the software crisis. Case tools can be divided into six categories business analysis and modeling. Development tools such as debugging environments, verification and validation tools, configuration management metrics and measurement, and project management. 
20世纪80年代中期，`计算机辅助软件工程（CASE）技术`也呈蓬勃发展之势，*这在一定程度上缓解了软件危机*。案例工具可分为六大类：业务分析与建模。开发工具，例如调试环境、验证与确认工具、配置管理的指标与度量，以及项目管理。

Now, the term software engineer is often used interchangeably with software developer, but there are subtle differences. Software engineers are also developers, but the term software developer is usually deemed narrower in scope than that of a software engineer. Software engineers knowledge is usually broader. Software engineers take a systematic big picture approach in their thinking to software development, whereas developers may have more creative approaches. And both software engineers and software developers have specialized knowledge, but software engineers use that knowledge to build entire systems, whereas software developers use their knowledge to write code to implement specific functionality within a system. Software engineers are often employed on larger scale projects, and they are focused on the broad structure rather than solving an immediate problem, software engineers are tasked with designing, building, and maintaining software systems. Their responsibilities include writing and testing code and consulting with stakeholders such as clients, third party software vendors, security specialists, and other team members. 
如今，“软件工程师”一词常常与“软件开发人员”互换使用，但两者之间仍存在一些细微的差别。软件工程师也是开发者，但“软件开发人员”这一术语的适用范围通常比“软件工程师”更为狭窄。**`软件工程师`的知识面通常更为广泛，软件工程师在软件开发过程中倾向于采用系统化的全局思维**。而`软件开发人员`则可能更注重创造性。软件工程师和软件开发人员都具备专业知识，但 **`软件工程师`运用这些知识来构建整个系统，而`软件开发人员`则利用其知识编写代码，以实现系统中的特定功能**。***`软件工程师`通常参与规模较大的项目，他们更关注系统的整体架构，而非解决眼前的某个具体问题。他们的职责是设计、构建并维护软件系统***。他们的职责包括编写并测试代码，以及与客户、第三方软件供应商、安全专家及其他团队成员等利益相关方进行沟通和协作。

The adoption of a measured scientific approach to software development has influenced the way software is created and designed today. The development process is typically guided by the software development lifecycle, or Sdlc. The Sdlc identifies the steps needed to develop high quality software. Later in this module, we will discuss the Sdlc, the traits of high quality software, and roles common in the field of software engineering in you learned, that is, the To and development of software. 
**在软件开发中采用严谨的科学方法，已深刻影响了当今软件的构建与设计方式**。开发过程通常以`软件开发生命周期`，即`SDLC`为指导。软件开发生命周期**明确了开发高质量软件所需的各个步骤**。在本模块的后续部分，我们将探讨软件生命周期、高质量软件的特征，以及软件工程领域常见的角色与职责，即软件的开发与演进。

Responsibilities of a software engineer include designing, building and maintaining software systems, writing and testing code, and consulting with stakeholders, third party vendors, security specialists, and other team members. And finally, software engineers build systems while software developers implement specific functionalities.
软件工程师的职责包括设计、构建和维护软件系统，编写并测试代码，以及与利益相关方、第三方供应商、安全专家及其他团队成员开展沟通与协作。最后，***`软件工程师`负责构建系统，而`软件开发人员`则负责实现具体的功能***。
